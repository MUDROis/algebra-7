Глава 1 • §2, п. 6

Тождества и тождественные преобразования

Математические близнецы и искусство упрощать

Привет! 👋 Сегодня знакомимся с тождествами — равенствами, которые верны ВСЕГДА, при любых значениях букв. Это как математические близнецы: два разных на вид выражения дают один и тот же результат. А ещё ты освоишь главный инструмент алгебры — упрощение выражений!

👯 Выражения-близнецы

Пример: всегда равны

Найдём значения выражений 3(x + y) и 3x + 3y при разных значениях:

x50-2
y417
3(x + y)27315
3x + 3y27315

Результаты совпали при любых значениях! Такие выражения называют тождественно равными.

Антипример: совпали случайно

Теперь сравним 2x + y и 2xy:

x13
y24
2x + y410
2xy424

⚠️ Важно

При x = 1, y = 2 значения совпали (оба равны 4) — но это случайность! При x = 3, y = 4 они уже разные. Значит, эти выражения НЕ являются тождественно равными.

📌 Определение

Два выражения, значения которых равны при любых значениях переменных, называются тождественно равными.

♾️ Что такое тождество?

📌 Определение

Тождество — это равенство, верное при любых значениях переменных.

3(x + y) = 3x + 3y — тождество ✅

Примеры тождеств, которые ты уже знаешь:

a + b = b + a   (a + b) + c = a + (b + c)

ab = ba   (ab)c = a(bc)   a(b + c) = ab + ac

a + 0 = a   a + (-a) = 0   a · 1 = a   (-a)(-b) = ab

Верные числовые равенства (например, 2 + 2 = 4) тоже считаются тождествами.

🏛 Минутка истории

Мухаммед бен Муса аль-Хорезми (787 — ок. 850) — среднеазиатский математик и астроном. Он впервые отделил алгебру от арифметики и стал рассматривать её как самостоятельный предмет. От его имени произошло слово «алгоритм», а от названия его трактата «аль-джебр» — слово «алгебра»!

🪄 Тождественное преобразование: зачем упрощать?

Заменив выражение тождественно равным ему, мы выполняем тождественное преобразование — и часто сильно упрощаем себе жизнь.

Сравни два пути:

Найдём значение xy - xz при x = 2,3, y = 0,8, z = 0,2.

Путь 1: «в лоб» (3 действия)

2,3 · 0,8 - 2,3 · 0,2 = 1,84 - 0,46 = 1,38

Путь 2: сначала упростить (2 действия)

xy - xz = x(y - z) = 2,3 · (0,8 - 0,2) = 2,3 · 0,6 = 1,38

Вынесли общий множитель — и вычислений стало меньше! ✨

🧲 Приведение подобных слагаемых

Подобные слагаемые — это слагаемые с одинаковой буквенной частью. Посмотри на сумму:

3a - 2a + b - 2c + 4a

Здесь 3a, -2a, 4a — подобные (буквенная часть «a»), а b и -2c — сами по себе.

📌 Правило приведения

Чтобы привести подобные слагаемые, нужно сложить их коэффициенты и результат умножить на общую буквенную часть.

📝 Пример 1

5x + 2x - 3x = (5 + 2 - 3)x = 4x

Преобразование основано на распределительном свойстве умножения.

✂️ Раскрытие скобок: плюс и минус

+ ( ... )

Скобки опускаем,
знаки сохраняем

2a + (b - 3c) = 2a + b - 3c

− ( ... )

Скобки опускаем,
знаки меняем на противоположные

a - (4b - c) = a - 4b + c

🔍 Почему минус меняет знаки?

Выражение -(4b - c) — это то же самое, что (-1) · (4b - c). Раскрываем скобки через распределительное свойство:

a - (4b - c) = a + (-1)(4b - c) = a + (-4b + c) = a - 4b + c

Вот и причина «переворота» знаков! Минус перед скобкой — это умножение на -1.

📮 Где это встречается в жизни?

Задача про альбомы с марками (№126а)

У Игоря три альбома. В первом — a марок, во втором — на 15 больше, чем в первом, а в третьем — втрое больше, чем во втором. Сколько марок в трёх альбомах?

a + (a + 15) + 3(a + 15) = a + a + 15 + 3a + 45 = 5a + 60

Раскрыли скобки, привели подобные — и получили короткую формулу! Если a = 20, то марок 5 · 20 + 60 = 160.

🎯 Методическая подсказка

🔥 Лайфхак: «невидимый коэффициент»

Самая частая ошибка при приведении подобных — потерять коэффициент 1. Запомни:

Шаг 1: У каждого слагаемого ЕСТЬ коэффициент, даже если он не написан:
x = 1 · x,   -x = -1 · x
Шаг 2: Складывая коэффициенты, не забывай невидимые:
5a + 27a - a = (5 + 27 - 1)a = 31a (а не 32a!)
Шаг 3: Проверь себя: сколько слагаемых было — столько коэффициентов должно участвовать в сумме.
a - 3a = (1 - 3)a = -2a ✅

👻 Невидимая единица — тоже число!

🟢 Уровень 1: Лёгкий

Задание 1 (№104 из учебника)

Какие свойства действий позволяют утверждать, что тождественно равны выражения:

а) ab + 16c и 16c + ab;   б) (a + 2) + x и a + (2 + x);

в) xy + 3 и 3 + xy;   г) 5(b + c) и 5b + 5c?

Ответ:
а) переместительное свойство сложения
б) сочетательное свойство сложения
в) переместительное свойство сложения
г) распределительное свойство умножения
🟢 Уровень 1: Лёгкий

Задание 2 (№108 из учебника)

Верно ли утверждение:

а) равенство 6(x - y) = 6x - 6y является тождеством;

б) равенство 3a - 4 = a + (2a - 4) является тождеством;

в) равенство 25(a - a) = 25 является тождеством?

Ответ:
а) верно (распределительное свойство)
б) верно: a + (2a - 4) = 3a - 4
в) неверно: 25(a - a) = 25 · 0 = 0, а не 25! 🚫
🔵 Уровень 2: Средний

Задание 3 (№119 а, в из учебника)

Упрости выражение (раскрой скобки):

а) 5 - (a - 3);   в) 64 - (14 + 7x)

Решение:
а) 5 - a + 3 = 8 - a (минус перед скобкой поменял знаки!)
в) 64 - 14 - 7x = 50 - 7x
🔵 Уровень 2: Средний

Задание 4 (№120 б, в из учебника)

Раскрой скобки и приведи подобные слагаемые:

б) 3x - (x - 2);   в) 4a - (a + 6)

Решение:
б) 3x - x + 2 = 2x + 2
в) 4a - a - 6 = 3a - 6 (не забудь невидимый коэффициент: 4 - 1 = 3!)
🟣 Уровень 3: Сложный

Задание 5 (№121 а, в из учебника)

Упрости выражение и найди его значение:

а) (5x - 1) - (2 - 8x) при x = 0,75;

в) 12 + 7x - (1 - 3x) при x = -1,7.

Решение:
а) 5x - 1 - 2 + 8x = 13x - 3; при x = 0,75: 13 · 0,75 - 3 = 9,75 - 3 = 6,75
в) 12 + 7x - 1 + 3x = 10x + 11; при x = -1,7: -17 + 11 = -6
Сначала упростили — потом подставили. Так намного легче считать!
🟣 Уровень 3: Сложный

Задание 6 (№123 из учебника)

Докажи, что при любом a значение выражения 3(a + 2) - 3a равно 6.

Доказательство:
3(a + 2) - 3a = 3a + 6 - 3a = (3 - 3)a + 6 = 0 · a + 6 = 6
Буква «исчезла» — значит, значение не зависит от a и всегда равно 6. ∎
Это и есть тождество: равенство верное при любом a!

📝 Главное, что нужно запомнить

  • Тождественно равные — выражения, равные при ЛЮБЫХ значениях переменных
  • Тождество — равенство, верное при любых значениях переменных
  • Тождественное преобразование — замена выражения тождественно равным (упрощение)
  • Подобные слагаемые — слагаемые с одинаковой буквенной частью
  • Приведение подобных: сложи коэффициенты (не забудь невидимый 1!) и умножь на общую буквенную часть
  • Скобки: после «+» знаки сохраняем, после «−» — меняем на противоположные
