Формулы

Как читать Jules Verne на языке математики и выводить новые формулы из старых

Привет! 👋 Откроем книгу Жюля Верна «Дети капитана Гранта»: птица jabiru «ростом в пять футов», клюв «восемнадцать дюймов», яхта «Дункан» идёт «семнадцать морских миль в час», температура «+74° по Фаренгейту»... Красиво, но непонятно! 😄 Чтобы перевести эти величины на привычный язык, нужны формулы. Сегодня учимся ими пользоваться — и даже выводить новые!

📖 Формулы-переводчики

Соотношения между старыми и современными единицами записываются формулами:

b = 30,48a
a — футы, b — сантиметры
l = 2,54m
m — дюймы, l — сантиметры
p = 1,853m
m — морские мили, p — километры
c = 5(f - 32) : 9
f — °F, c — °C

Переводим текст Жюля Верна

Рост птицы: b = 30,48 · 5 = 152,4 ≈ 152 см (≈ 1,5 м)

Клюв: l = 2,54 · 18 = 45,72 ≈ 46 см (≈ 0,5 м)

Скорость яхты: p = 1,853 · 17 = 31,501 ≈ 32 км/ч

Температура: c = 5 · (74 - 32) : 9 = 210 : 9 ≈ 23 °C

💡 Обрати внимание

Знак «≈» означает «приближённо равно»: учебник округляет результаты до целых, чтобы величины было легко представить. В ответах всегда помечай округление!

📈 Формулы в задачах на проценты

Пример 1 из учебника: площадь прямоугольника

Пусть длина прямоугольника a см, ширина b см, площадь S = ab. Увеличим длину и ширину на 10%:

S = ab
было: a и b
1,21ab
стало: 1,1a и 1,1b
  1. Новая длина: a + 0,1a = 1,1a; новая ширина: 1,1b
  2. Новая площадь: 1,1a · 1,1b = 1,21ab
  3. Прирост: 1,21ab - ab = 0,21ab, то есть (0,21ab : ab) · 100% = 21%

Ответ: площадь увеличится на 21% — а не на 20%, как подсказывает интуиция! 🎯

🔁 Из одной формулы — другую!

Свойства равенств позволяют из формулы, связывающей несколько переменных, получать новые формулы. Выразим из c = 5(f - 32) : 9 переменную f (чтобы переводить °C в °F):

  1. Умножим обе части на 9: 9c = 5(f - 32)
  2. Раскроем скобки: 9c = 5f - 160
  3. Перенесём -160 влево с другим знаком: 5f = 9c + 160
  4. Разделим обе части на 5: f = (9c + 160) : 5, то есть f = 1,8c + 32

📌 Проверка новой формулы

Подставим c = 23: f = 1,8 · 23 + 32 = 41,4 + 32 = 73,4 ≈ 74 °F — сошлось с условием книги! ✅ Выведенная формула работает.

🎯 Методическая подсказка

🔥 Лайфхак: процентный множитель

Любое изменение на p% — это просто умножение на коэффициент:

Увеличение на p%: умножь на 1 + 0,01p. Пример: +10% → · 1,1
Уменьшение на p%: умножь на 1 - 0,01p. Пример: -10% → · 0,9
Ловушка: товар стоил 200 р. Цену подняли на 10%: 200 · 1,1 = 220. Потом снизили на 10%: 220 · 0,9 = 198.
Интуиция кричит: «вернулась цена 200!» 🚫 Нет: 198 ≠ 200 ✅ Проценты считались от РАЗНЫХ баз!
Итог одним действием: 200 · 1,1 · 0,9 = 200 · 0,99 = 198 — суммарный множитель 0,99 показывает: цена упала на 1%.

🧮 В задании 6 тебя ждёт та же ловушка с +15% и -15% — проверь её множителями!

🟢 Уровень 1: Лёгкий

Задание 1 (№187 а, б из учебника)

Пользуясь формулой b = 1,067a (a — расстояние в верстах, b — в километрах), вырази в километрах расстояние, равное:

а) 6 верстам;   б) 12,5 версты.

Решение (подставляем в формулу):
а) b = 1,067 · 6 = 6,402 км
б) b = 1,067 · 12,5 = 13,3375 км
🟢 Уровень 1: Лёгкий

Задание 2 (№190 из учебника)

Пройденное расстояние считают по формуле s = nl (s — в метрах, n — число шагов, l — длина шага). Сколько километров прошёл человек, если длина шага 60 см, а шагов сделано 1800?

Решение:
Переведём шаг в метры: l = 60 см = 0,6 м
s = 1800 · 0,6 = 1080 м
Переведём в километры: 1080 м = 1,08 км
Ответ: 1,08 км. Единицы измерения — половина успеха!
🔵 Уровень 2: Средний

Задание 3 (№191 из учебника)

Как изменится площадь прямоугольника, если:

а) его длину и ширину уменьшить на 10%;

б) его длину увеличить на 30%, а ширину уменьшить на 30%?

Решение (процентные множители):
а) 0,9a · 0,9b = 0,81ab → площадь уменьшится на 19%
б) 1,3a · 0,7b = 0,91ab → площадь уменьшится на 9%
«+30% и -30%» не компенсируют друг друга!
🔵 Уровень 2: Средний

Задание 4 (№195а из учебника)

Какой температуре по Фаренгейту соответствует 4 °C; -15 °C; 0 °C? (Используй формулу f = 1,8c + 32.)

Решение:
c = 4: f = 1,8 · 4 + 32 = 7,2 + 32 = 39,2 °F
c = -15: f = 1,8 · (-15) + 32 = -27 + 32 = 5 °F (число в скобках!)
c = 0: f = 1,8 · 0 + 32 = 32 °F
🟣 Уровень 3: Сложный

Задание 5 (№197 а, б из учебника)

Вырази из формулы:

а) s = at — переменную t;

б) b = u + at — переменную a.

Решение:
а) Разделим обе части на a (a ≠ 0): t = s : a
б) Перенесём u: b - u = at; разделим на t (t ≠ 0): a = (b - u) : t
Не забудь указать, что делитель не равен нулю!
🟣 Уровень 3: Сложный

Задание 6 (№193 из учебника)

Цену товара сначала повысили на 15%, а затем снизили на 15%. Первоначальная цена — a р., окончательная — b р. Сравни числа a и b (выбери верный ответ): 1) a > b; 2) a < b; 3) a = b; 4) сравнить нельзя.

Решение (множители):
b = a · 1,15 · 0,85 = a · 0,9775 = 0,9775a
Так как 0,9775 < 1, то b < a, то есть a > b.
Ответ: вариант 1. Цена в итоге стала НИЖЕ первоначальной — ловушка из подсказки!

⭐ Доп. №208

Составь формулу числа:

а) кратного 11;   б) кратного 21.

Ответ:
а) m = 11n, где n — целое число
б) m = 21n, где n — целое число
Проверка: n = 2 → m = 42, делится на 21 ✅
⭐ Доп. №209

Вырази в километрах расстояния 10 миль, 50 миль, 250 миль, пользуясь формулой y = 1,853x (x — морские мили, y — километры).

Решение:
y = 1,853 · 10 = 18,53 км
y = 1,853 · 50 = 92,65 км
y = 1,853 · 250 = 463,25 км
⭐ Доп. №246

Если к задуманному числу прибавить 7, полученную сумму умножить на 3 и из произведения вычесть 47, то получится задуманное число. Какое число задумано?

Решение:
Пусть задумано x. По условию: 3(x + 7) - 47 = x
3x + 21 - 47 = x → 3x - 26 = x → 2x = 26 → x = 13
Проверка: 13 + 7 = 20; 20 · 3 = 60; 60 - 47 = 13 ✅
Ответ: 13.

📝 Главное, что нужно запомнить

  • Формула — равенство, показывающее, как одна величина выражается через другие
  • Работа с формулой: подставь значение и вычисли, следя за единицами измерения (см → м → км!)
  • Процентный множитель: +p% → ·(1 + 0,01p); -p% → ·(1 - 0,01p)
  • Последовательные «+p% и -p%» НЕ возвращают исходное значение (0,99; 0,91; 0,9775...)
  • Из формулы можно выразить любую переменную через остальные: умножай/дели обе части, переноси слагаемые
  • При делении обеих частей формулы указывай условие: делитель ≠ 0
  • Старинные единицы (верста, пуд, фут, дюйм) связаны с современными формулами — математика читает даже Жюля Верна!
