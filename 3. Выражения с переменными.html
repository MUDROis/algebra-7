Глава 1 • §3

Выражения с переменными

Буквы, которые работают как числа

Привет! 👋 Сегодня ты узнаешь, зачем в математике нужны буквы. Спойлер: это не чтобы запутать тебя, а чтобы одной записью решать тысячи похожих задач. Представь, что выражение — это машина: ты загружаешь в неё число, а она выдаёт результат!

🚗 Машина, которая считает за нас

Пример из учебника: автомобиль в пути

Автомобиль едет со скоростью 60 км/ч. Какой путь он пройдёт за разное время?

за 2 ч:60 · 2 = 120 км
за 3 ч:60 · 3 = 180 км
за 5,5 ч:60 · 5,5 = 330 км
за t ч:60 · t = 60t км

Одна запись 60t заменяет все строки таблицы!

📥 ВХОД
значение t
2; 3; 5,5...
→
⚙️ МАШИНА
60t
(умножь на 60)
→
📤 ВЫХОД
значение выражения
120; 180; 330...

💡 Новые слова

Переменная — буква, значение которой можно менять (здесь это t).

Выражение с переменной — выражение, в котором есть такие буквы (здесь это 60t).

🔢 Как найти значение выражения с переменными?

Если вместо каждой переменной подставить число, получится обычное числовое выражение. Его значение и называют значением выражения с переменными.

Пример: площадь прямоугольника

Стороны прямоугольника — a см и b см. Его площадь: ab (кв. см). Здесь две переменные!

📝 Подставляем значения

Если a = 8 и b = 11, то ab = 8 · 11 = 88

Если a = 25 и b = 4, то ab = 25 · 4 = 100

Алгоритм из 3 шагов:

  1. Подставь число вместо буквы.
  2. Вычисли, соблюдая порядок действий.
  3. Запиши ответ — это значение выражения.

⚠️ Когда выражение «ломается»?

Рассмотрим выражение b / (b - 3).

При b = 13:   13 / (13 - 3) = 13 / 10 = 1,3 ✅ всё работает

При b = 3:   знаменатель 3 - 3 = 0 → деление на ноль! 🚫

🚫 Запомни

Говорят: при b = 3 выражение не имеет смысла.

А вот выражения a² - 10, x(x + 1), ay - 4,3 имеют смысл при любых значениях переменных — в них нельзя получить деление на ноль.

🧬 Формулы: выражения-законы

Выражения с переменными используют для записи формул — правил, которые верны всегда.

m = 2n — формула чётного числа (n — целое)

m = 2n + 1 — формула нечётного числа

m = 3n — формула числа, кратного 3

💡 Проверь себя

Подставь в m = 2n числа n = 5; -2; 10. Получатся 10; -4; 20 — все чётные! Формула работает как закон природы. ✨

🎯 Методическая подсказка

🔥 Лайфхак: подставляй отрицательные числа ТОЛЬКО в скобках!

Самая частая ошибка в 7 классе — потерянный минус при подстановке. Вот как её избежать:

Шаг 1: Выражение: 4x - 12, нужно подставить x = -5
Шаг 2: Ставим число в скобках: 4 · (-5) - 12
Шаг 3: Умножаем: 4 · (-5) = -20
Шаг 4: Вычитаем: -20 - 12 = -32

📌 Отрицательное число без скобок = гарантированная ошибка!

✏️ Проверь себя

Задания идут от простого к сложному. Нажми "Проверить", чтобы увидеть ответ!

🟢 Уровень 1: Лёгкий

Задание 1 (№37а из учебника)

Найди значения выражения 4x - 12 при x = 7; 0; -5

Решение:
При x = 7: 4 · 7 - 12 = 28 - 12 = 16
При x = 0: 4 · 0 - 12 = -12
При x = -5: 4 · (-5) - 12 = -20 - 12 = -32 (число в скобках!)
🟢 Уровень 1: Лёгкий

Задание 2 (№53 из учебника)

Длина прямоугольника a см, ширина b см. Что означают выражения?

ab;  2a + 2b;  a + b;  2a

Ответ:
ab — площадь прямоугольника
2a + 2b — периметр
a + b — полупериметр (сумма длины и ширины)
2a — удвоенная длина (сумма двух длин)
🔵 Уровень 2: Средний

Задание 3 (№38 из учебника)

Заполни таблицу для выражений 3x - 1 и -3x + 1 и сделай вывод:

x-2-1012
3x - 1?????
-3x + 1?????
Ответ:
3x - 1:  -7; -4; -1; 2; 5
-3x + 1:  7; 4; 1; -2; -5
Вывод: соответствующие значения — противоположные числа! ✨
🔵 Уровень 2: Средний

Задание 4 (№47 из учебника)

С первого участка (a га) собирают по 32 ц пшеницы с гектара, со второго (b га) — по 40 ц. Составь выражение и вычисли его при a = 120, b = 80.

Решение:
Выражение: 32a + 40b
32 · 120 + 40 · 80 = 3840 + 3200 = 7040
Ответ: 7040 центнеров пшеницы
🟣 Уровень 3: Сложный

Задание 5 (№58 из учебника)

Какое из выражений имеет смысл при любом значении a?

14 / (a² + 1)  или  14 / (a² - 1)

Ответ: 14 / (a² + 1)
Потому что a² ≥ 0, значит a² + 1 ≥ 1 — никогда не ноль! ✅
А вот a² - 1 = 0 при a = 1 и a = -1 — там выражение не имеет смысла. 🚫
🟣 Уровень 3: Сложный

Задание 6 (№60 из учебника)

Напиши формулу числа, кратного 7, и найди по ней два трёхзначных числа, кратных 7.

Ответ:
Формула: m = 7n, где n — целое число
При n = 15: m = 105 ✅
При n = 100: m = 700 ✅
Оба числа трёхзначные и делятся на 7!

📝 Главное, что нужно запомнить

  • Переменная — буква, значение которой можно менять
  • Выражение с переменной — «машина»: вход (число) → выход (значение)
  • Чтобы найти значение выражения — подставь число и вычисли
  • Отрицательные числа подставляем только в скобках!
  • Если при подстановке получается деление на ноль — выражение не имеет смысла
  • Формулы: чётное m = 2n, нечётное m = 2n + 1, кратное k: m = kn
