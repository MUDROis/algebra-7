Глава 6 • §15, п. 44

Способ сложения

Складываем уравнения почленно — и переменная исчезает на глазах ✨

Привет! 👋 Вот система из учебника: \(2x + 3y = -5\) и \(x - 3y = 38\). Смотри, что произойдёт, если сложить эти уравнения почленно: слагаемые \(+3y\) и \(-3y\) дадут ноль и испарятся! Останется \(3x = 33\) — уравнение с одной переменной, которое решается в уме. Это и есть способ сложения — третий и, пожалуй, самый элегантный способ решения систем. Сегодня научишься складывать уравнения так, чтобы неизвестные исчезали 🔥

💡 Суть способа: почему сложение работает

Главная идея. При решении систем способом сложения, как и при решении способом подстановки, мы переходим от данной системы к другой, равносильной ей системе, в которой одно из уравнений содержит только одну переменную.

Откуда берётся такое уравнение? Если коэффициенты при одной из переменных — противоположные числа (например, \(+3\) и \(-3\)), то при почленном сложении уравнений эта переменная полностью исчезает. А если коэффициенты одинаковые (например, \(4\) и \(4\)), достаточно предварительно умножить одно из уравнений на \(-1\).

Способ сложения особенно удобен, когда выражать одну переменную через другую при подстановке трудно или неудобно — например, коэффициенты большие или дробные.

⚖️ Весы сложения: пример 1 из учебника

«Весы сложения»: складываем левые части с левыми, правые с правыми — и переменная y «испаряется» 💥

Пример 1. Решим систему уравнений {

\(2x + 3y = -5\),
\(x - 3y = 38\).

  1. В уравнениях системы коэффициенты при \(y\) — числа \(3\) и \(-3\), они противоположные.
  2. Сложим почленно левые и правые части: \((2x + x) + (3y + (-3y)) = -5 + 38\). Получим \(3x = 33\).
  3. Заменим первое уравнение системы уравнением \(3x = 33\). Новая система \(3x = 33\) и \(x - 3y = 38\) равносильна данной.
  4. Из уравнения \(3x = 33\) находим \(x = 11\). Подставим во второе уравнение: \(11 - 3y = 38\), откуда \(-3y = 27\), \(y = -9\).
  5. Проверка по обоим уравнениям: \(2 \cdot{} 11 + 3 \cdot{} (-9) = 22 - 27 = -5\) ✓ и \(11 - 3 \cdot{} (-9) = 11 + 27 = 38\) ✓.

Ответ: \((11; -9)\)

Любопытно и геометрически: графики уравнений \(2x + 3y = -5\), \(x - 3y = 38\) и \(3x = 33\) — три прямые, и все они пересекаются в одной и той же точке \((11; -9)\) (в учебнике это рисунок 95). Именно поэтому замену уравнения при сложении можно делать безболезненно: решение системы не меняется.

📋 Алгоритм способа сложения

При решении системы двух линейных уравнений с двумя переменными способом сложения поступают следующим образом:

  1. умножают почленно уравнения системы, подбирая множители так, чтобы коэффициенты при одной из переменных стали противоположными числами;
  2. складывают почленно левые и правые части уравнений системы;
  3. решают получившееся уравнение с одной переменной;
  4. находят соответствующее значение второй переменной.

Важно. Заметим, что если коэффициенты при одной из переменных уже являются противоположными числами, то решение сразу начинают с почленного сложения уравнений — первый шаг пропускают.

🔁 Умножаем уравнения целиком: примеры 2 и 3 из учебника

Пример 2. Решим систему {

\(5x + 11y = 8\),
\(10x - 7y = 74\).

Здесь почленное сложение ничего не даст: \(5x\) и \(10x\), \(11y\) и \(-7y\) не уничтожаются. Но если умножить все члены первого уравнения на \(-2\), коэффициенты при \(x\) станут противоположными: получим \(-10x - 22y = -16\). Складываем со вторым уравнением: \(-29y = 58\), откуда \(y = -2\). Подставим во второе уравнение: \(10x - 7 \cdot{} (-2) = 74\), то есть \(10x + 14 = 74\), \(x = 6\). Проверка: \(5 \cdot{} 6 + 11 \cdot{} (-2) = 30 - 22 = 8\) ✓ и \(10 \cdot{} 6 - 7 \cdot{} (-2) = 60 + 14 = 74\) ✓.

Ответ: \((6; -2)\)

Пример 3. Здесь множители нужны обоим уравнениям: {

\(3x - 5y = 93\),
\(5x - 4y = 103\).

Подберём множители так, чтобы коэффициенты при \(y\) стали противоположными: умножим первое уравнение на \(-4\), а второе на \(5\): \(-12x + 20y = -372\) и \(25x - 20y = 515\). Складываем: \(13x = 143\), \(x = 11\). Подставим в уравнение \(5x - 4y = 103\): \(55 - 4y = 103\), откуда \(y = -12\). Проверка: \(3 \cdot{} 11 - 5 \cdot{} (-12) = 33 + 60 = 93\) ✓ и \(5 \cdot{} 11 - 4 \cdot{} (-12) = 55 + 48 = 103\) ✓.

Ответ: \((11; -12)\)

🚨 Ловушка: множитель умножается на каждый член уравнения, включая правую часть. Забыл знак у правой части — и вся система «поехала».

🎯 Методическая подсказка: «Сделай противоположности»

Добейся, чтобы коэффициенты при одной переменной стали противоположными: умножь уравнение на \(-1\) или на число — всё уравнение, оба члена! Потом складывай — переменная исчезнет.

Пример: \(x + y = 7\) и \(x - y = 3\). Коэффициенты при \(y\) уже противоположные — складываем: \(2x = 10\), значит \(x = 5\), тогда \(y = 2\). Проверка: \(5 - 2 = 3\) ✓

✅ Правильно: умножил \(x - y = 3\) на \(-1\) целиком — получил \(-x + y = -3\) (и слева, и справа знаки сменились). Сложил с \(x + y = 7\): \(2y = 4\), \(y = 2\) — тот же ответ, что и при сложении напрямую.
🚫 Ошибка: умножил «наполовину» — получил \(-x + y = 3\), забыв поменять знак в правой части. Тогда сложение даст \(2y = 10\), \(y = 5\), но проверка \(x - y = 3\) с парой \((2; 5)\) даёт \(2 - 5 = -3\), а не \(3\) — провал!

Мостик: в задании 2 ты как раз «уравняешь» коэффициенты — умножишь одно из уравнений на \(-1\), чтобы одинаковые коэффициенты стали противоположными, а дальше — сложение.

✏️ Проверь себя

Задания взяты из учебника (п. 44) и идут от простого к сложному. Нажми «Проверить», чтобы увидеть полный ход решения!

🟢 Уровень 1: Лёгкий | Задание 1 (№1098 а из учебника)

Решите систему уравнений: {

\(2x + 11y = 15\),
\(10x - 11y = 9\).

  1. Коэффициенты при \(y\) — числа \(11\) и \(-11\), они противоположные. Складываем почленно: \((2x + 10x) + (11y + (-11y)) = 15 + 9\), то есть \(12x = 24\).
  2. Из уравнения \(12x = 24\) находим \(x = 2\).
  3. Подставим в первое уравнение: \(2 \cdot{} 2 + 11y = 15\), отсюда \(11y = 11\), \(y = 1\).
  4. Проверка во втором уравнении: \(10 \cdot{} 2 - 11 \cdot{} 1 = 20 - 11 = 9\) — верно.

Ответ: \((2; 1)\)

🟢 Уровень 1: Лёгкий | Задание 2 (№1098 в из учебника)

Решите систему уравнений: {

\(4x - 7y = 30\),
\(4x - 5y = 90\).

  1. Коэффициенты при \(x\) одинаковые — оба по \(4\). Умножим все члены первого уравнения на \(-1\): \(-4x + 7y = -30\). Теперь при \(x\) коэффициенты противоположные.
  2. Складываем почленно: \((-4x + 4x) + (7y - 5y) = -30 + 90\), то есть \(2y = 60\), откуда \(y = 30\).
  3. Подставим в первое уравнение: \(4x - 7 \cdot{} 30 = 30\), значит \(4x = 240\), \(x = 60\).
  4. Проверка во втором уравнении: \(4 \cdot{} 60 - 5 \cdot{} 30 = 240 - 150 = 90\) — верно.

Ответ: \((60; 30)\)

🔵 Уровень 2: Средний | Задание 3 (№1101 а из учебника)

Решите систему уравнений: {

\(12x - 7y = 2\),
\(4x - 5y = 6\).

  1. При \(x\) коэффициенты \(12\) и \(4\). Умножим все члены второго уравнения на \(-3\): \(-12x + 15y = -18\).
  2. Складываем почленно: \((12x - 12x) + (-7y + 15y) = 2 + (-18)\), то есть \(8y = -16\), откуда \(y = -2\).
  3. Подставим во второе уравнение: \(4x - 5 \cdot{} (-2) = 6\), значит \(4x + 10 = 6\), \(4x = -4\), \(x = -1\).
  4. Проверка в первом уравнении: \(12 \cdot{} (-1) - 7 \cdot{} (-2) = -12 + 14 = 2\) — верно.

Ответ: \((-1; -2)\)

🔵 Уровень 2: Средний | Задание 4 (№1103 б из учебника)

Составьте уравнение вида \(y = kx + b\), график которого проходит через точки Р\((4; 1)\) и Q\((3; -5)\).

  1. Подставим координаты точки Р\((4; 1)\) в равенство \(y = kx + b\): получим \(4k + b = 1\).
  2. Подставим координаты точки \(Q(3; -5)\): получим \(3k + b = -5\). Вместе эти уравнения образуют систему.
  3. Коэффициенты при \(b\) одинаковые. Умножим второе уравнение на \(-1\) и сложим с первым: \(4k - 3k = 1 + 5\), откуда \(k = 6\).
  4. Тогда из первого уравнения \(b = 1 - 4 \cdot{} 6 = -23\).
  5. Проверка по второй точке: \(6 \cdot{} 3 - 23 = 18 - 23 = -5\) — верно, прямая проходит через точку Q\((3; -5)\).

Ответ: \(y = 6x - 23\)

🟣 Уровень 3: Сложный | Задание 5 (№1106 из учебника)

График линейной функции пересекает ось \(x\) в точке с абсциссой 4, а ось \(y\) — в точке с ординатой 11. Задайте эту функцию формулой.

  1. Переведём слова на язык координат: пересечение оси \(x\) в точке с абсциссой 4 — это точка \((4; 0)\); пересечение оси \(y\) в точке с ординатой 11 — это точка \((0; 11)\).
  2. Функция линейная: \(y = kx + b\). Для точки \((0; 11)\): \(k \cdot{} 0 + b = 11\), значит \(b = 11\).
  3. Для точки \((4; 0)\): \(4k + b = 0\), значит \(4k = -11\), \(k = -\frac{11}{4} = -2,75\).
  4. Проверка: \(-2,75 \cdot{} 4 + 11 = -11 + 11 = 0\) — график действительно проходит через точку \((4; 0)\).

Ответ: \(y = -2,75x + 11\)

🟣 Уровень 3: Сложный | Задание 6 (№1097 из учебника)

Докажите, что все точки графика функции, заданной формулой \(y = x^2 - 4x + 5\), расположены в верхней полуплоскости.

  1. Точка лежит в верхней полуплоскости, если её ордината положительна. Значит, достаточно доказать, что \(y \gt 0\) при любом \(x\).
  2. Выделим полный квадрат: \(x^2 - 4x + 5 = x^2 - 4x + 4 + 1 = (x - 2)^2 + 1\).
  3. Квадрат \((x - 2)^2\) неотрицателен при любом значении \(x\), поэтому \(y = (x - 2)^2 + 1 ≥ 1\), а значит \(y \gt 0\) всегда.
  4. Проверка числом: при \(x = 2\) получаем \(y = 1\) — самое маленькое значение функции, и даже оно больше нуля. Значит, весь график лежит выше оси \(x\), что и требовалось доказать.

Ответ: все точки графика расположены в верхней полуплоскости

📝 Главное, что нужно запомнить

  • Способ сложения — третий способ решения систем линейных уравнений (после графического и способа подстановки).
  • При сложении мы переходим к равносильной системе, в которой одно уравнение содержит только одну переменную.
  • Алгоритм: уравняй коэффициенты (умножь уравнения на подходящие множители) → сложи почленно → реши уравнение с одной переменной → найди вторую переменную.
  • Если коэффициенты при одной переменной уже противоположные — начинай сразу со сложения, без умножения.
  • Умножать можно только всё уравнение целиком: каждый член слева и правую часть.
  • Одинаковые коэффициенты (4 и 4) превращаются в противоположные умножением одного уравнения на \(-1\).
  • Проверка: подставь найденную пару в оба исходных уравнения.
  • Геометрически все прямые — старые и новые уравнения — проходят через одну точку, и это решение системы.
