Глава 5 • §12, п. 35

Разложение разности квадратов на множители

Два точных квадрата и минус между ними — скобки собираются сами 🧩

Привет! 👋 Со станций М и N, расстояние между которыми 380 км, одновременно вышли навстречу друг другу два поезда — так начинается задача №898 из учебника, и её щёлкает тот, кто дружит с формулами. Сегодня мы прочитаем знакомую формулу задом наперёд: не «скобки → разность квадратов», а «разность квадратов → скобки». Учебник называет это разложением на множители. Один взгляд на двучлен — и ты уже знаешь, соберётся ли из него пара скобок. Проверим? 🚂

🔄 Формула читается наоборот

В п. 34 мы умножали скобки и получали разность квадратов. Поменяем местами правую и левую части этого тождества — и получим инструмент для разложения на множители:

\(a^2 - b^2 = (a - b)(a + b)\)

Определение. Тождество \(a^2 - b^2 = (a - b)(a + b)\) называют формулой разности квадратов: разность квадратов двух выражений равна произведению разности этих выражений и их суммы. Её применяют для разложения на множители разности квадратов любых двух выражений.

Пример 1 из учебника — разложим на множители выражение \(36 - a^2\):

  1. Первый член — точный квадрат: \(36 = 6^2\).
  2. Вытащили корни: \(36 - a^2 = 6^2 - a^2\).
  3. По формуле: \(6^2 - a^2 = (6 - a)(6 + a)\).

Пример 2 из учебника — представим в виде произведения двучлен \(49x^2 - 16y^6\):

  1. \(49x^2 = (7x)^2\), ведь \(7^2 = 49\).
  2. \(16y^6 = (4y^3)^2\), ведь \(4^2 = 16\) и \((y^3)^2 = y^6\).
  3. Собираем скобки: \(49x^2 - 16y^6 = (7x - 4y^3)(7x + 4y^3)\).

Проверка умножением: \((7x - 4y^3)(7x + 4y^3) = 49x^2 - 16y^6\) — верно ✅. Второй пример показывает главное: корни бывают «высокие» — не только числа, но и степени.

🃏 Ищи два квадрата: карточный детектор

Как быстро понять, раскладывается ли двучлен? Прогони его через детектор — три проверки:

  1. Первый член — точный квадрат. Чего именно? Вытащи основание.
  2. Второй член — тоже точный квадрат.
  3. Между ними стоит МИНУС.

Все проверки зелёные — собирай пару скобок из найденных оснований. Вот как детектор обрабатывает выражение \(a^4 - 81\):

точный квадрат — корень вытащился сумма квадратов — не раскладывается собранные скобки

Карточный детектор для \(a^4 - 81\): оба члена — квадраты (\(a^4 = (a^2)^2\), \(81 = 9^2\)), между ними минус. Скобка \(a^2 - 9\) — снова разность квадратов, раскладываем ещё раз

Доделываем то, что показал детектор: \(a^4 - 81 = (a^2 - 9)(a^2 + 9) = (a - 3)(a + 3)(a^2 + 9)\). А скобка-сумма \(a^2 + 9\) дальше не раскладывается — это её окончательный вид. Полезно держать в голове таблицу «высоких» корней:

  • \(x^4 = (x^2)^2\) — основание \(x^2\);
  • \(x^6 = (x^3)^2\) — основание \(x^3\);
  • \(0,09 = 0,3^2\) и \(0,25 = 0,5^2\) — квадраты бывают и дробные;
  • \(1,44 = 1,2^2\) — десятичные тоже.

🚦 Сумма квадратов молчит

Железное правило: сумма квадратов на множители-многочлены не раскладывается. Сравни соседей:

  • ✅ \(25 - m^2 = (5 - m)(5 + m)\) — между квадратами минус, формула работает.
  • 🚫 \(25 + m^2\) — сумма квадратов: ни одна формула сокращённого умножения сюда не подходит, скобок не будет.

Если минус стоит первым — не пугайся, просто переставь слагаемые: \(-49 + c^2 = c^2 - 49 = (c - 7)(c + 7)\).

Разложение мощно помогает решать уравнения. Пример: \(y^2 - 25 = 0\).

  1. Раскладываем левую часть: \(y^2 - 25 = (y - 5)(y + 5)\).
  2. Произведение равно нулю, когда хотя бы один множитель равен нулю: \(y - 5 = 0\) или \(y + 5 = 0\).
  3. Два корня: \(y = 5\) или \(y = -5\).

Проверка: \(5^2 - 25 = 0\) и \((-5)^2 - 25 = 0\) ✅. Без формулы пришлось бы гадать — а тут оба корня видны сразу. 💡

🧮 Жизненный блок: квадраты без столбика

Формула — чемпион устного счёта. Пример: найдём \(54^2 - 46^2\). В лоб — два возведения в столбик и вычитание. А теперь красиво:

  1. \(54^2 - 46^2 = (54 - 46)(54 + 46)\).
  2. \(54 - 46 = 8\), а \(54 + 46 = 100\).
  3. \(8 \cdot{} 100 = 800\). Десять секунд! ⚡

Проверка в лоб: \(2916 - 2116 = 800\) — сошлось. И совсем короткий: \(18^2 - 17^2 = (18 - 17)(18 + 17) = 1 \cdot{} 35 = 35\). Такие фокусы выручают и на контрольной, и когда перепроверяешь чек в магазине без калькулятора. 🛒

🎯 Методическая подсказка: «Ищи два квадрата»

Формула \(a^2 - b^2 = (a - b)(a + b)\) срабатывает только при двух условиях: ОБА члена — точные квадраты и между ними стоит МИНУС. Поэтому алгоритм один: сначала вытащи корень из каждого члена.

Устный пример (не из заданий): \(49 - x^6 = 7^2 - (x^3)^2 = (7 - x^3)(7 + x^3)\). Корни «высокие»: \(49 = 7^2\), а \(x^6 = (x^3)^2\). 🃏

✅ \(9y^2 - 16 = (3y - 4)(3y + 4)\) — оба члена квадраты (\(9y^2 = (3y)^2\), \(16 = 4^2\)), между ними минус. Работает!

🚫 \(9y^2 + 16\) — всё то же самое, но между квадратами ПЛЮС. Сумма квадратов не раскладывается — детектор красный, скобок не будет.

🎯 Мостик: в задании 2 вытащишь корни из степеней, в задании 4 отправишь корни в уравнение, а в задании 5 дробь свернётся в устный пример.

🟢 Уровень 1: Лёгкий | Задание 1 (№900 в, г из учебника)

Разложите на множители: \(36a^2 - 49\); \(64 - 25x^2\)

Прогоняем каждый двучлен через детектор «два квадрата и минус»:

  1. \(36a^2 = (6a)^2\), \(49 = 7^2\) — оба члена квадраты, минус на месте.
  2. \(36a^2 - 49 = (6a - 7)(6a + 7)\).
  3. Проверка умножением: \((6a - 7)(6a + 7) = 36a^2 + 42a - 42a - 49 = 36a^2 - 49\) ✅.
  4. \(64 = 8^2\), \(25x^2 = (5x)^2\): \(64 - 25x^2 = (8 - 5x)(8 + 5x)\).
  5. Проверка: \((8 - 5x)(8 + 5x) = 64 + 40x - 40x - 25x^2 = 64 - 25x^2\) ✅.

Ответ: \((6a - 7)(6a + 7); (8 - 5x)(8 + 5x)\)

🟢 Уровень 1: Лёгкий | Задание 2 (№899 а из учебника)

Разложите на множители многочлен: \(x^4 - y^4\)

Корни здесь «высокие» — вытащи их из степеней.

  1. Проверяем на квадраты: \(x^4 = (x^2)^2\) и \(y^4 = (y^2)^2\) — оба члена квадраты, минус на месте.
  2. Первый шаг: \(x^4 - y^4 = (x^2 - y^2)(x^2 + y^2)\).
  3. Первая скобка — снова разность квадратов: \(x^2 - y^2 = (x - y)(x + y)\).
  4. Итог: \(x^4 - y^4 = (x - y)(x + y)(x^2 + y^2)\).
  5. Проверка умножением: \((x - y)(x + y) = x^2 - y^2\), затем \((x^2 - y^2)(x^2 + y^2) = x^4 - y^4\) ✅. Скобка \(x^2 + y^2\) — сумма квадратов, дальше не раскладывается.

Ответ: \((x - y)(x + y)(x^2 + y^2)\)

🔵 Уровень 2: Средний | Задание 3 (№902 а, в из учебника)

Вычислите: \(47^2 - 37^2\); \(126^2 - 74^2\)

Не спеши возводить в столбик — разность квадратов считается устно.

  1. \(47^2 - 37^2 = (47 - 37)(47 + 37) = 10 \cdot{} 84 = 840\).
  2. Проверка в лоб: \(47^2 = 2209\), \(37^2 = 1369\), \(2209 - 1369 = 840\) ✅.
  3. \(126^2 - 74^2 = (126 - 74)(126 + 74) = 52 \cdot{} 200 = 10400\).
  4. Проверка в лоб: \(126^2 = 15876\), \(74^2 = 5476\), \(15876 - 5476 = 10400\) ✅.

Ответ: \(840; 10400\)

🔵 Уровень 2: Средний | Задание 4 (№906 а, ж из учебника)

Решите уравнение: \(x^2 - 16 = 0\); \(4x^2 - 9 = 0\)

Раскладываем левую часть — и корни проявляются сами.

  1. \(x^2 - 16 = (x - 4)(x + 4)\).
  2. \((x - 4)(x + 4) = 0\), значит \(x - 4 = 0\) или \(x + 4 = 0\): \(x = 4\) или \(x = -4\).
  3. Проверка: \(4^2 - 16 = 0\) и \((-4)^2 - 16 = 0\) ✅.
  4. Во втором уравнении \(4x^2 = (2x)^2\), поэтому \(4x^2 - 9 = (2x - 3)(2x + 3)\).
  5. \(2x - 3 = 0\) даёт \(x = 1,5\); \(2x + 3 = 0\) даёт \(x = -1,5\).
  6. Проверка: \(4 \cdot{} 2,25 - 9 = 9 - 9 = 0\) ✅.

Ответ: \(x = ±4; x = ±1,5\)

🟣 Уровень 3: Сложный | Задание 5 (№903 в, г из учебника)

Найдите значение дроби: \((53^2 - 27^2)/(79^2 - 51^2)\); \((53^2 - 32^2)/(61^2 - 44^2)\)

И числитель, и знаменатель — разности квадратов. Сворачиваем каждый в произведение:

  1. Числитель первой дроби: \(53^2 - 27^2 = (53 - 27)(53 + 27) = 26 \cdot{} 80 = 2080\).
  2. Её знаменатель: \(79^2 - 51^2 = (79 - 51)(79 + 51) = 28 \cdot{} 130 = 3640\).
  3. Дробь: \(\frac{2080}{3640}\) — сокращаем на 520 (ведь \(2080 = 4 \cdot{} 520\), \(3640 = 7 \cdot{} 520\)): получится \(\frac{4}{7}\).
  4. Вторая дробь: числитель \(53^2 - 32^2 = (53 - 32)(53 + 32) = 21 \cdot{} 85 = 1785\).
  5. Её знаменатель: \(61^2 - 44^2 = (61 - 44)(61 + 44) = 17 \cdot{} 105 = 1785\).
  6. Числитель и знаменатель равны — дробь равна \(1\).
  7. Проверка в лоб: \(2809 - 729 = 2080\), \(6241 - 2601 = 3640\) ✅; \(2809 - 1024 = 1785\), \(3721 - 1936 = 1785\) ✅.

Ответ: \(\frac{4}{7}; 1\)

🟣 Уровень 3: Сложный | Задание 6 (№915 из учебника, сюжетная задача)

На сторонах прямоугольника построены квадраты. Площадь одного квадрата на \(95\) квадратных сантиметров больше площади другого. Найдите периметр прямоугольника, если известно, что длина прямоугольника на \(5\) см больше его ширины.

Схема к №915: квадраты построены на сторонах прямоугольника (в учебнике — рис. 88). Их площади — \(a^2\) и \(b^2\)

Переводим сюжет на язык алгебры — и формула срабатывает.

  1. Пусть длина прямоугольника — \(a\) см, ширина — \(b\) см. По условию \(a - b = 5\).
  2. Квадраты построены на сторонах, их площади — \(a^2\) и \(b^2\). Разность площадей: \(a^2 - b^2 = 95\).
  3. Формула разности квадратов: \(a^2 - b^2 = (a - b)(a + b)\), значит \(5 \cdot{} (a + b) = 95\).
  4. Отсюда \(a + b = 19\).
  5. Периметр — это удвоенная сумма сторон: \(P = 2(a + b) = 2 \cdot{} 19 = 38\) (см).
  6. Проверка: из \(a - b = 5\) и \(a + b = 19\) находим \(a = 12\), \(b = 7\); тогда \(12^2 - 7^2 = 144 - 49 = 95\) ✅ и \(2 \cdot{} (12 + 7) = 38\) ✅.

Ответ: \(38\) см

📝 Главное, что нужно запомнить

  • Формула наоборот: \(a^2 - b^2 = (a - b)(a + b)\) — разность квадратов раскладывается на два множителя.
  • Правило из учебника: разность квадратов двух выражений равна произведению разности этих выражений и их суммы.
  • Перед разложением проверь: оба члена — точные квадраты и между ними минус.
  • Корни бывают «высокие»: \(x^4 = (x^2)^2\), \(x^6 = (x^3)^2\), \(0,09 = 0,3^2\), \(1,44 = 1,2^2\).
  • Сумма квадратов \(a^2 + b^2\) на множители-многочлены не раскладывается.
  • Внутри может прятаться ещё одна разность квадратов: \(x^4 - y^4 = (x - y)(x + y)(x^2 + y^2)\) — раскладывай поэтапно.
  • Уравнение \(x^2 - c^2 = 0\) имеет два корня: \(x = c\) и \(x = -c\).
  • Устный счёт: \(54^2 - 46^2 = (54 - 46)(54 + 46) = 8 \cdot{} 100 = 800\).
