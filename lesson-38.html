Глава 5 • §13, п. 38

Применение различных способов для разложения на множители

Три замка разведчика: вынеси множитель, сверни по формуле, сгруппируй 🔓

Привет! 👋 Учебник в п. 38 говорит прямо: иногда удаётся разложить многочлен на множители, применив последовательно несколько способов, — и начинать стоит с вынесения общего множителя за скобки. Зачем это нужно? Вот пример из учебника: значение многочлена \(5x^3 + 2x^2 - 7x + 4\) при \(x = 1,2\) мучительно считать в лоб, но если превратить его в цепочку \(((5x + 2)x - 7)x + 4\), ответ \(7,12\) находится почти устно. Сегодня ты научишься проводить такие цепочки сам: три замка — и многочлен разложен до конца. 🗝️

🔧 Три инструмента — одна цепочка

У тебя уже есть три инструмента для разложения на множители: вынесение общего множителя за скобки, группировка и формулы сокращённого умножения. Учебник соединяет их в один приём:

Правило. Иногда удаётся разложить многочлен на множители, применив последовательно несколько способов. При этом начинать преобразование следует, если это возможно, с вынесения общего множителя за скобки.

Пример 1 из учебника — разложим на множители многочлен \(10a^3 - 40a\):

  1. Члены имеют общий множитель \(10a\). Выносим: \(10a^3 - 40a = 10a(a^2 - 4)\).
  2. К выражению \(a^2 - 4\) применима формула разности квадратов: \(10a(a^2 - 4) = 10a(a - 2)(a + 2)\).
  3. Проверка умножением: \((a - 2)(a + 2) = a^2 - 4\), затем \(10a(a^2 - 4) = 10a^3 - 40a\) ✅.

Заметь: остановиться на шаге \(10a(a^2 - 4)\) нельзя — разложение не доведено до конца. Как не пропустить ни одного шага? Прогнать многочлен через чек-лист с тремя замками. Смотри, как он работает:

замок открыт — переход к следующему шагу результат шага ловушка-остановка

Три замка на цепочке \(a^3 - 9a\): сначала общий множитель, затем формула разности квадратов; группировка не нужна — разложение полное

🔗 Сначала вынесем — потом сгруппируем

Пример 2 из учебника — разложим на множители многочлен \(ab^3 - 3b^3 + ab^2y - 3b^2y\):

  1. Замок 1: общий множитель у всех четырёх членов — \(b^2\). Выносим: \(ab^3 - 3b^3 + ab^2y - 3b^2y = b^2(ab - 3b + ay - 3y)\).
  2. Замок 3: группируем внутри скобок: \(ab - 3b + ay - 3y = b(a - 3) + y(a - 3) = (a - 3)(b + y)\).
  3. Окончательно: \(ab^3 - 3b^3 + ab^2y - 3b^2y = b^2(a - 3)(b + y)\).
  4. Проверка умножением: \(b^2(ab + ay - 3b - 3y) = ab^3 + ab^2y - 3b^3 - 3b^2y\) — те же слагаемые ✅.

Здесь понадобились два замка из трёх, причём группировка сработала уже внутри скобок. Именно так рождаются «длинные» цепочки: каждый открытый замок открывает следующий.

🕵️ Спрятанный квадрат

Пример 3 из учебника — разложим на множители многочлен \(a^2 - 4ax - 9 + 4x^2\). Здесь группировка особая: три члена собираются в квадрат разности.

  1. Группируем первый, второй и четвёртый члены: \(a^2 - 4ax + 4x^2 = (a - 2x)^2\).
  2. Переписываем: \(a^2 - 4ax - 9 + 4x^2 = (a^2 - 4ax + 4x^2) - 9 = (a - 2x)^2 - 3^2\).
  3. Разность квадратов: \((a - 2x)^2 - 3^2 = (a - 2x - 3)(a - 2x + 3)\).
  4. Проверка числом: при \(a = 5\), \(x = 1\) слева \(25 - 20 - 9 + 4 = 0\), справа \((5 - 2 - 3)(5 - 2 + 3) = 0 \cdot{} 6 = 0\) ✅.

Важное замечание из учебника: при разложении многочлена на множители имеют в виду представление его в виде произведения нескольких многочленов, в котором хотя бы два множителя являются многочленами ненулевой степени (то есть не являются числами). И ещё: не каждый многочлен можно разложить на множители — например, \(x^2 + 1\) и \(4x^2 - 2x + 1\) так и остаются целыми выражениями.

🧮 Считаем по цепочке: фокус с калькулятором

Зачем всё это? Учебник показывает: разложение помогает быстро вычислять. Пример 4: найдём значение многочлена \(5x^3 + 2x^2 - 7x + 4\) при \(x = 1,2\).

  1. Превращаем многочлен в цепочку: \(5x^3 + 2x^2 - 7x + 4 = (5x^2 + 2x - 7)x + 4 = ((5x + 2)x - 7)x + 4\).
  2. Считаем по шагам: \(5 \cdot{} 1,2 + 2 = 8\); затем \(8 \cdot{} 1,2 - 7 = 2,6\); затем \(2,6 \cdot{} 1,2 + 4 = 7,12\).
  3. Проверка «в лоб»: \(1,2^3 = 1,728\) и \(1,2^2 = 1,44\), тогда \(5 \cdot{} 1,728 + 2 \cdot{} 1,44 - 7 \cdot{} 1,2 + 4 = 8,64 + 2,88 - 8,4 + 4 = 7,12\) ✅.

Ответ один и тот же, но цепочка короче и удобнее даже для калькулятора — учебник советует попробовать оба способа в парах в упражнении №964. 🧮

🎯 Методическая подсказка: «Чек-лист разведчика»

Разложил один раз — не всё! Проверяй ДО КОНЦА, пока в скобках остаются скобки: 1) есть ли общий множитель? 2) работает ли формула (квадрат, разность квадратов, кубы)? 3) поможет ли группировка? Потом пройди список ещё раз — уже по новым скобкам.

Устный пример (не из заданий): \(2m^3n + 4m^2n^2 + 2mn^3\).

✅ \(2m^3n + 4m^2n^2 + 2mn^3 = 2mn(m^2 + 2mn + n^2) = 2mn(m + n)^2\) — замок 1 (общий множитель \(2mn\)), замок 2 (квадрат суммы), замок 3 не нужен. Разложение полное.

🚫 Остановиться на \(2mn(m^2 + 2mn + n^2)\) — разведка брошена: в скобках остался неразложенный квадрат суммы, второй замок не открыт.

🎯 Мостик: в задании 1 прогонишь чек-лист дважды — сначала вынесение, потом формула; в задании 2 откроешь замок-группировку; в задании 3 найдёшь спрятанный квадрат; а в заданиях 5 и 6 тот же чек-лист превратится в план решения задачи на движение.

🟢 Уровень 1: Лёгкий | Задание 1 (№955 а, б из учебника)

Разложите на множители: а) \(3x^2 + 6xy + 3y^2\); б) \(-m^2 + 2m - 1\)

Прогоняем каждый пример через чек-лист разведчика.

  1. а) Замок 1: все члены делятся на \(3\) — выносим: \(3x^2 + 6xy + 3y^2 = 3(x^2 + 2xy + y^2)\).
  2. Замок 2: в скобках квадрат суммы: \(x^2 + 2xy + y^2 = (x + y)^2\). Итог: \(3(x + y)^2\).
  3. Проверка умножением: \(3(x + y)^2 = 3(x^2 + 2xy + y^2) = 3x^2 + 6xy + 3y^2\) ✅.
  4. б) Замок 1: общий множитель \(-1\): \(-m^2 + 2m - 1 = -(m^2 - 2m + 1)\).
  5. Замок 2: квадрат разности: \(m^2 - 2m + 1 = (m - 1)^2\). Итог: \(-(m - 1)^2\).
  6. Проверка: \(-(m - 1)^2 = -(m^2 - 2m + 1) = -m^2 + 2m - 1\) ✅.

Ответ: \(3(x + y)^2; -(m - 1)^2\)

🟢 Уровень 1: Лёгкий | Задание 2 (№963 а из учебника)

Представьте в виде произведения: \(a - b + a^2 - b^2\)

Общего множителя у всех членов нет — зато часть выражения знакома.

  1. Замок 3: группировка: \(a - b + a^2 - b^2 = (a - b) + (a^2 - b^2)\).
  2. Ко второй части применим разность квадратов: \(a^2 - b^2 = (a - b)(a + b)\).
  3. Теперь у обеих групп общий множитель \((a - b)\): \((a - b) + (a - b)(a + b) = (a - b)(1 + a + b)\).
  4. Проверка умножением: \((a - b)(1 + a + b) = a + a^2 + ab - b - ab - b^2 = a - b + a^2 - b^2\) ✅.

Ответ: \((a - b)(a + b + 1)\)

🔵 Уровень 2: Средний | Задание 3 (№960 б из учебника)

Выполните разложение на множители: \(c^2 + 2c + 1 - a^2\)

Чек-лист разведчика найдёт здесь спрятанный квадрат.

  1. Первые три члена — квадрат суммы: \(c^2 + 2c + 1 = (c + 1)^2\).
  2. Переписываем четырёхчлен: \(c^2 + 2c + 1 - a^2 = (c + 1)^2 - a^2\).
  3. Это разность квадратов: \((c + 1)^2 - a^2 = (c + 1 - a)(c + 1 + a)\).
  4. Проверка умножением: \((c + 1 - a)(c + 1 + a) = (c + 1)^2 - a^2 = c^2 + 2c + 1 - a^2\) ✅.

Ответ: \((c + 1 - a)(c + 1 + a)\)

🔵 Уровень 2: Средний | Задание 4 (№970 а из учебника)

Упростите выражение и найдите его значение при \(x = 0,2\): \((6x - 1)(6x + 1) - (12x - 5)(3x + 1)\)

Сначала упрощаем, потом подставляем число.

  1. Разность квадратов: \((6x - 1)(6x + 1) = 36x^2 - 1\).
  2. Раскрываем второе произведение: \((12x - 5)(3x + 1) = 36x^2 + 12x - 15x - 5 = 36x^2 - 3x - 5\).
  3. Вычитаем: \(36x^2 - 1 - (36x^2 - 3x - 5) = 36x^2 - 1 - 36x^2 + 3x + 5 = 3x + 4\).
  4. При \(x = 0,2\): \(3 \cdot{} 0,2 + 4 = 0,6 + 4 = 4,6\).
  5. Проверка «в лоб» при \(x = 0,2\): \((1,2 - 1)(1,2 + 1) = 0,2 \cdot{} 2,2 = 0,44\); \((2,4 - 5)(0,6 + 1) = -2,6 \cdot{} 1,6 = -4,16\); \(0,44 - (-4,16) = 4,6\) ✅.

Ответ: \(3x + 4; 4,6\)

🟣 Уровень 3: Сложный | Задание 5 (№948 из учебника, сюжетная задача на движение)

От деревни до станции велосипедист ехал со скоростью \(15\) км/ч, а обратно он возвращался со скоростью \(10\) км/ч. Найдите расстояние от деревни до станции, если известно, что на обратный путь велосипедист затратил на \(1\) ч больше, чем на путь от деревни до станции.

Переводим сюжет на язык алгебры — выручает вынесение общего множителя.

  1. Пусть расстояние от деревни до станции — \(s\) км. Тогда время «туда» — \(s/15\) ч, время «обратно» — \(s/10\) ч.
  2. Обратный путь занял на \(1\) ч больше: \(s/10 - s/15 = 1\).
  3. Выносим \(s\) за скобки (замок 1!): \(s(\frac{1}{10} - \frac{1}{15}) = 1\).
  4. Считаем в скобках: \(\frac{1}{10} - \frac{1}{15} = \frac{3}{30} - \frac{2}{30} = \frac{1}{30}\), значит \(s/30 = 1\).
  5. Отсюда \(s = 30\) (км).
  6. Проверка «в лоб»: \(30 : 15 = 2\) ч на станцию и \(30 : 10 = 3\) ч обратно; разность \(3 - 2 = 1\) ч ✅.

Ответ: \(30\) км

🟣 Уровень 3: Сложный | Задание 6 (№949 из учебника, сюжетная задача на движение)

Из пункта А связной доставил донесение в пункт В за \(30\) мин. На обратном пути он уменьшил скорость на \(1\) км/ч и затратил на дорогу \(36\) мин. Определите, с какой скоростью шёл связной из пункта А в пункт В.

Расстояние одно и то же — приравниваем два способа его вычисления.

  1. Пусть скорость связного из А в В — \(v\) км/ч. Время: \(30\) мин = \(0,5\) ч, значит путь АВ равен \(0,5v\) км.
  2. Обратно скорость \(v - 1\) км/ч, время \(36\) мин = \(0,6\) ч: путь равен \(0,6(v - 1)\) км.
  3. Приравниваем: \(0,5v = 0,6(v - 1)\).
  4. Раскрываем скобки: \(0,5v = 0,6v - 0,6\); переносим: \(-0,1v = -0,6\).
  5. Значит \(v = 0,6 : 0,1 = 6\) (км/ч).
  6. Проверка: путь \(6 \cdot{} 0,5 = 3\) км; обратно \(3 : 5 = 0,6\) ч = \(36\) мин ✅.

Ответ: \(6\) км/ч

📝 Главное, что нужно запомнить

  • Три способа разложения — вынесение общего множителя, группировка, формулы сокращённого умножения — можно применять последовательно, один за другим.
  • Начинать преобразование следует, если это возможно, с вынесения общего множителя за скобки.
  • Чек-лист разведчика: общий множитель? → формула? → группировка? Повторяй, пока в скобках остаются скобки.
  • Эталонная цепочка: \(a^3 - 9a = a(a^2 - 9) = a(a - 3)(a + 3)\).
  • Спрятанный квадрат: \(a^2 - 4ax - 9 + 4x^2 = (a - 2x)^2 - 3^2 = (a - 2x - 3)(a - 2x + 3)\).
  • Не каждый многочлен раскладывается: \(x^2 + 1\) и \(4x^2 - 2x + 1\) — исключения; в разложении хотя бы два множителя должны быть многочленами ненулевой степени.
  • Цепочка \(((5x + 2)x - 7)x + 4\) упрощает вычисления: значение \(5x^3 + 2x^2 - 7x + 4\) при \(x = 1,2\) равно \(7,12\).
  • Вынесение выручает и в задачах на движение: \(s/10 - s/15 = s(\frac{1}{10} - \frac{1}{15}) = s/30\).
