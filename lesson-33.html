Глава 5 • §11, п. 33

Разложение на множители с помощью формул квадрата суммы и квадрата разности

Три улики — и трёхчлен сворачивается в аккуратную скобку 🕵️

Привет! 👋 В прошлый раз ты разворачивал скобку в трёхчлен. Сегодня — обратное расследование: перед тобой три члена, и нужно вычислить, какая скобка их «оставила». Учебник говорит прямо: формулы квадрата суммы и квадрата разности применяются не только для возведения в квадрат, но и для разложения на множители выражений вида \(a^2 + 2ab + b^2\) и \(a^2 - 2ab + b^2\). Готов? Шерлок Холмс алгебры, твой выход! 🔍

🔄 Формулы работают в обе стороны

Поменяем в формулах п. 32 левую и правую части — и получим равенства для разложения на множители:

\(a^2 + 2ab + b^2 = (a + b)^2\)   и   \(a^2 - 2ab + b^2 = (a - b)^2\)

Определение. Представление трёхчлена в виде произведения двух одинаковых множителей называют разложением на множители по формуле квадрата суммы или квадрата разности: трёхчлен \(a^2 + 2ab + b^2\) можно записать как \((a + b)(a + b)\), а трёхчлен \(a^2 - 2ab + b^2\) — как \((a - b)(a - b)\). Такую скобку называют квадратом двучлена.

Пример: свернём трёхчлен \(x^2 + 16x + 64\).

  1. Первый член: \(x^2\) — квадрат \(x\).
  2. Последний: \(64 = 8^2\) — квадрат \(8\).
  3. Средний: \(16x = 2 \cdot{} x \cdot{} 8\) — удвоенное произведение. Всё сходится!
  4. Сворачиваем: \(x^2 + 16x + 64 = (x + 8)^2\).

Проверка умножением: \((x + 8)^2 = x^2 + 2 \cdot{} x \cdot{} 8 + 8^2 = x^2 + 16x + 64\) — верно. ✅

🕵️ Детективная доска: три улики

Как понять, что трёхчлен — это квадрат двучлена, если он тебе просто попался в упражнении? Проверь три улики:

  1. Улика первая. Первый член — точный квадрат. Чьего? Запиши основание.
  2. Улика вторая. Последний член — тоже точный квадрат.
  3. Улика третья. Средний член равен удвоенному произведению этих оснований (со знаком «плюс» или «минус»).

Все три улики сходятся? Трёхчлен сворачивается: плюс у среднего — в \((a + b)^2\), минус — в \((a - b)^2\). Вот как это выглядит на доске детектива (пример 1 из учебника):

Детективная доска: три улики о трёхчлене \(9x^2 + 30x + 25\) приводят к одному «подозреваемому» — скобке \((3x + 5)^2\)

Оформим, как в учебнике: \(9x^2 + 30x + 25 = (3x)^2 + 2 \cdot{} 3x \cdot{} 5 + 5^2 = (3x + 5)^2\). Готово — три члена превратились в произведение \((3x + 5)(3x + 5)\). 🎉

🧗 Квадраты бывают высокие

Основанием квадрата может быть любое выражение — даже многочлен или число со степенью. Настоящие квадраты-рекордсмены:

  • \(a^4 = (a^2)^2\) — основание \(a^2\);
  • \(100b^10 = (10b^5)^2\) — основание \(10b^5\);
  • \(0,25x^2 = (0,5x)^2\) — основание \(0,5x\);
  • \(49m^6 = (7m^3)^2\) — основание \(7m^3\).

Пример 2 из учебника — разложим на множители трёхчлен \(a^4 - 20a^2b^5 + 100b^10\):

  1. Улика первая: \(a^4 = (a^2)^2\).
  2. Улика вторая: \(100b^10 = (10b^5)^2\).
  3. Улика третья: \(20a^2b^5 = 2 \cdot{} a^2 \cdot{} 10b^5\). Минус у среднего — значит, квадрат разности.
  4. Сворачиваем: \(a^4 - 20a^2b^5 + 100b^10 = (a^2 - 10b^5)^2 = (a^2 - 10b^5)(a^2 - 10b^5)\).

Не пугайся «небоскрёбов» из степеней: просто спроси себя — квадратом чего является этот член? 🔭

🚦 Минус-сигнал: когда минус снаружи

Если все три члена трёхчлена с минусом, сперва вынеси \(-1\) за скобку, а внутри сворачивай обычный квадрат:

\(-9x^2 - 6x - 1 = -(9x^2 + 6x + 1) = -(3x + 1)^2\)

Полученное выражение в учебнике называют выражением, противоположным квадрату двучлена — именно так сформулировано задание №855.

⚠️ Но минус не может прятаться только в последнем члене! Смотри контраст:

  • ✅ \(y^2 - 10y + 25 = (y - 5)^2\) — последний член \(25 = 5^2\) с плюсом;
  • 🚫 \(y^2 - 10y - 25\) — не свернётся: последний член отрицательный, а квадрат не бывает отрицательным. Вторая улика провалена.

⚡ Жизненный блок: считаем в обратную сторону

Формулы в обратную сторону — секретное оружие устного счёта. Пример 1: вычислим \(72^2 + 2 \cdot{} 72 \cdot{} 28 + 28^2\).

  1. В «лоб» — умножай три больших числа, трать минуту.
  2. А узнай в трёхчлене квадрат суммы: \(72^2 + 2 \cdot{} 72 \cdot{} 28 + 28^2 = (72 + 28)^2\).
  3. \(72 + 28 = 100\), значит значение выражения — \(100^2 = 10000\). Секунда! ⚡

Пример 2: \(43^2 - 86 \cdot{} 13 + 13^2\). Хитрость в том, что \(86 \cdot{} 13 = 2 \cdot{} 43 \cdot{} 13\), поэтому

\(43^2 - 86 \cdot{} 13 + 13^2 = (43 - 13)^2 = 30^2 = 900\)

Такой трюк работает всегда, когда видишь «квадрат + удвоенное произведение + квадрат». Всё, что пугает в лоб, после сворачивания считается в одно действие.

🎯 Методическая подсказка: «Детектив среднего члена»

Трёхчлен сворачивается в квадрат двучлена, только если сходятся три улики:

  1. первый член — точный квадрат;
  2. последний член — точный квадрат;
  3. средний член равен \(±2\) · (основание первого) · (основание последнего).

Проверил все три — и только потом сворачивай. Главный подозреваемый всегда «средний член»: если он не сходится, дело закрыто.

Пример (не из заданий): \(x^2 + 6x + 9\) — улики: \(x^2\), \(9 = 3^2\), \(6x = 2 \cdot{} x \cdot{} 3\). Все сходятся ✅ → \((x + 3)^2\).

🚫 А вот \(x^2 + 6x + 8\) не свернётся: \(8\) — не точный квадрат, вторая улика провалена. Честный детектив не подгоняет ответ: не каждый трёхчлен — полный квадрат.

🎯 Мостик: в задании 2 станешь детективом — улики там спрятаны внутри больших коэффициентов. А в заданиях 5 и 6 свёрнутый квадрат станет главным доказательством.

🟢 Уровень 1: Лёгкий | Задание 1 (№849 в из учебника)

Представьте трёхчлен в виде квадрата двучлена: \(a^2 + 12a + 36\)

Собираем улики:

  1. Первый член: \(a^2\) — квадрат \(a\).
  2. Последний член: \(36 = 6^2\) — квадрат \(6\).
  3. Средний член: \(12a = 2 \cdot{} a \cdot{} 6\) — удвоенное произведение. Плюс → квадрат суммы.
  4. Сворачиваем: \(a^2 + 12a + 36 = (a + 6)^2\).

Проверка умножением: \((a + 6)^2 = a^2 + 2 \cdot{} a \cdot{} 6 + 6^2 = a^2 + 12a + 36\) — верно. ✅

Ответ: \((a + 6)^2\)

🟢 Уровень 1: Лёгкий | Задание 2 (№851 а из учебника)

Преобразуйте трёхчлен в квадрат двучлена: \(81a^2 - 18ab + b^2\)

Здесь улики спрятаны в коэффициентах — работаем детективом:

  1. Первый член: \(81a^2 = (9a)^2\), потому что \(9^2 = 81\).
  2. Последний член: \(b^2\) — квадрат \(b\).
  3. Средний член: \(18ab = 2 \cdot{} 9a \cdot{} b\). Минус → квадрат разности.
  4. Сворачиваем: \(81a^2 - 18ab + b^2 = (9a - b)^2\).

Проверка умножением: \((9a - b)^2 = 81a^2 - 2 \cdot{} 9a \cdot{} b + b^2 = 81a^2 - 18ab + b^2\) — верно. ✅

Ответ: \((9a - b)^2\)

🔵 Уровень 2: Средний | Задание 3 (№856 а из учебника)

Найдите значение выражения: \(y^2 - 2y + 1\) при \(y = 101; -11; 0,6\)

Сначала сворачиваем, потом подставляем — иначе придётся считать трижды «в лоб».

  1. Улики: \(y^2\), \(1 = 1^2\), средний \(2y = 2 \cdot{} y \cdot{} 1\). Значит, \(y^2 - 2y + 1 = (y - 1)^2\).
  2. При \(y = 101\): \((101 - 1)^2 = 100^2 = 10000\).
  3. При \(y = -11\): \((-11 - 1)^2 = (-12)^2 = 144\).
  4. При \(y = 0,6\): \((0,6 - 1)^2 = (-0,4)^2 = 0,16\).

Проверка «в лоб» для \(y = 0,6\): \(0,36 - 1,2 + 1 = 0,16\) — сошлось. ✅

Ответ: \(10000; 144; 0,16\)

🔵 Уровень 2: Средний | Задание 4 (№852 б из учебника)

Поставьте вместо знака * такой одночлен, чтобы трёхчлен можно было представить в виде квадрата двучлена: \(36 - 12x + *\)

Расследование наоборот: по двум известным членам вычисляем пропавшего свидетеля.

  1. Первый член: \(36 = 6^2\) — основание \(6\).
  2. Средний член должен быть удвоенным произведением: \(-12x = 2 \cdot{} 6 \cdot{} (-x)\) — второе основание \(x\).
  3. Значит, пропавший одночлен — квадрат \(x\): \(* = x^2\).
  4. Проверяем: \(36 - 12x + x^2 = 6^2 - 2 \cdot{} 6 \cdot{} x + x^2 = (6 - x)^2\) — квадрат двучлена получен.

Проверка при \(x = 2\): трёхчлен \(36 - 24 + 4 = 16\), скобка \((6 - 2)^2 = 16\) — сошлось. ✅

Ответ: \(x^2\)

🟣 Уровень 3: Сложный | Задание 5 (№857 б из учебника, найди ловушку)

Верно ли, что при любых значениях \(x\) выполняется неравенство \(x^2 + 20x + 100 \gt 0\)?

Свернём трёхчлен и аккуратно проверим слова «при любых».

  1. Улики: \(x^2\), \(100 = 10^2\), \(20x = 2 \cdot{} x \cdot{} 10\). Значит, \(x^2 + 20x + 100 = (x + 10)^2\).
  2. Квадрат любого выражения всегда неотрицателен: \((x + 10)^2 ≥ 0\).
  3. Но нуля он всё-таки достигает! При \(x = -10\) получаем \((-10 + 10)^2 = 0\), а \(0\) — это не строго больше нуля.
  4. Значит, утверждение «больше нуля при любых значениях» — неверно: контрпример найден.

Контрпроверка: при \(x = -10\) значение равно \(100 - 200 + 100 = 0\) — не положительное. 🚫

Ответ: нет, при \(x = -10\) значение равно \(0\)

🟣 Уровень 3: Сложный | Задание 6 (№863 из учебника, доказательство)

Докажите, что при любом значении \(x\) многочлен \(x^2 + 6x + 10\) принимает положительные значения.

Стратегия: выделить полный квадрат — и неравенство станет очевидным.

  1. Разбиваем \(10\) на две части так, чтобы получился полный квадрат: \(x^2 + 6x + 10 = (x^2 + 6x + 9) + 1\).
  2. Три первых члена сворачиваем по уликам \(x^2\), \(9 = 3^2\), \(6x = 2 \cdot{} x \cdot{} 3\): \(x^2 + 6x + 9 = (x + 3)^2\).
  3. Итого: \(x^2 + 6x + 10 = (x + 3)^2 + 1\).
  4. Квадрат всегда неотрицателен: \((x + 3)^2 ≥ 0\), поэтому \((x + 3)^2 + 1 ≥ 1\).
  5. Наименьшее значение равно \(1\) и достигается при \(x = -3\) — положительность гарантирована при любом \(x\).

Проверка числами: при \(x = -3\) значение \(9 - 18 + 10 = 1\), при \(x = 0\) значение \(10\) — оба положительны. ✅

Ответ: многочлен принимает положительные значения при любом \(x\)

📝 Главное, что нужно запомнить

  • Формулы читаются в обе стороны: \(a^2 + 2ab + b^2 = (a + b)^2\) и \(a^2 - 2ab + b^2 = (a - b)^2\).
  • Три улики полного квадрата: первый член — квадрат, последний — квадрат, средний — \(±2\) · (основание) · (основание).
  • Трёхчлен-квадрат — это произведение двух одинаковых множителей: \((a + b)(a + b)\).
  • Основания бывают «высокие»: \(a^4 = (a^2)^2\), \(100b^10 = (10b^5)^2\), \(0,25x^2 = (0,5x)^2\).
  • Минус перед всеми тремя членами? Вынеси \(-1\): \(-9x^2 - 6x - 1 = -(3x + 1)^2\).
  • Квадрат всегда \(≥ 0\): поэтому \(x^2 + 6x + 10 = (x + 3)^2 + 1\) положителен при любом \(x\).
  • Средняя улика не сходится — сворачивать нельзя: не каждый трёхчлен является квадратом двучлена.
