Глава 2 • §4, п. 14

График функции

Как одна линия может рассказать больше, чем таблица из ста строк

Привет! 👋 Представь: врач смотрит на кардиограмму и за секунды понимает, как работает сердце. Метеоролог глядит на график температуры и предсказывает погоду. Биржевой аналитик по одной кривой решает, покупать или продавать акции. Во всех этих случаях люди читают график функции — линию, которая показывает, как одна величина зависит от другой. Сегодня ты научишься строить такие линии и «читать» их!

📈 Что такое график функции?

📌 Определение

Графиком функции называется множество всех точек координатной плоскости, абсциссы (x) которых равны значениям аргумента, а ординаты (y) — соответствующим значениям функции.

Проще говоря: берём каждую пару (x; y) из таблицы и ставим на координатной плоскости точку. Все эти точки вместе образуют линию — график.

Пример из учебника: y = 6/(x + 3) на отрезке [−2; 3]

x−2−10123
y6321,51,21

График функции y = 6/(x + 3) на отрезке [−2; 3]. Равный масштаб: 1 ед. = 50 px по обеим осям; точки совпадают с таблицей.

Чем больше точек отметим — тем точнее получится линия. Для простых функций (например, прямых) достаточно двух точек, а для сложных кривых — десятки.

👀 Как читать график: три главных вопроса

1
x → y (вперёд)
Зная аргумент, найти значение функции. Поднять перпендикуляр из точки на оси X до графика, затем провести горизонталь к оси Y.
2
y → x (назад)
Зная значение функции, найти аргумент(ы). Провести горизонталь от оси Y до графика, затем опустить перпендикуляр на ось X.
3
Точка ∈ график?
Проверить, лежит ли точка (a; b) на графике. Подставить x = a в формулу и проверить, получится ли y = b.

✅ Принадлежит ли точка графику?

Если известна формула функции, можно обойтись без чертежа. Достаточно подставить координаты точки в формулу и проверить равенство.

Пример: функция y = 3 − 2x

Точка M(0; 3): подставляем x = 0: \(y = 3 − 2\cdot{}0 = 3\). Равенство \(3 = 3\) верное → точка лежит на графике ✅

Точка N(2; 5): подставляем x = 2: \(y = 3 − 2\cdot{}2 = 3 − 4 = -1\). Равенство \(5 = -1\) неверное → точка не лежит на графике 🚫

⚠️ Важное правило

Если подстановка дала верное равенство — точка принадлежит графику. Если равенство неверное — точка лежит вне графика. Никаких «примерно» и «почти»!

🌡️ Где это встречается в жизни?

График температуры воздуха за сутки

Представь, что метеоролог каждый час записывал температуру и построил график. Что можно узнать без формул?

  • 🔍 В 9 утра было около +15°C (смотрим по x = 9)
  • 🌡️ Самая высокая температура — около +28°C в 15:00 (ищем «пик» графика)
  • ❄️ Ниже нуля температура опускалась с 22:00 до 6:00 (где график ниже оси X)
  • 📈 Температура росла с 6:00 до 15:00 (график идёт вверх)
  • 📉 Температура падала с 15:00 до 22:00 (график идёт вниз)

Видишь? Одна линия рассказала целую историю о сутках — и всё это без единой формулы!

🎯 Методическая подсказка

🔥 Лайфхак: три чтения любого графика

Любой график можно «прочитать» тремя способами. Потренируемся на функции \(y = x^{2}\) (парабола) и точке \((3; 9)\):

Чтение 1: вперёд (x → y)
Возьми \(x = 3\), подставь в формулу: \(y = 3^{2} = 9\). Значит, при x = 3 значение функции равно 9. На графике это точка \((3; 9)\).
Чтение 2: назад (y → x)
Возьми \(y = 4\). Решаем уравнение \(x^{2} = 4\) → \(x = 2\) или \(x = -2\). Значит, значение y = 4 функция принимает при двух разных x. На графике горизонтальная линия y = 4 пересечёт параболу в двух точках!
Чтение 3: проверка точки
Точка \((3; 9)\): подставляем → \(9 = 3^{2}\) → \(9 = 9\) ✅ точка на графике
Точка \((2; 5)\): подставляем → \(5 = 2^{2}\) → \(5 = 4\) 🚫 точка НЕ на графике

📊 В задании 1 ты проверишь три точки на графике \(y = 2x - 6\) — действуй по третьему чтению!

🟢 Уровень 1: Лёгкий

Задание 1 (№284 из учебника)

Принадлежат ли графику функции \(y = 2x - 6\) точки: A(4; 2), B(1; −4), C(1; 4)? Назови ещё две точки, принадлежащие этому графику.

Решение (подстановка в формулу):
A(4; 2): \(y = 2\cdot{}4 - 6 = 8 - 6 = 2\). Равенство \(2 = 2\) верное → точка принадлежит ✅
B(1; −4): \(y = 2\cdot{}1 - 6 = 2 - 6 = -4\). Равенство \(-4 = -4\) верное → точка принадлежит ✅
C(1; 4): \(y = 2\cdot{}1 - 6 = -4\). Равенство \(4 = -4\) неверное → точка не принадлежит 🚫
Ещё две точки: возьмём x = 0: \(y = 2\cdot{}0 - 6 = -6\) → точка \((0; -6)\); возьмём x = 3: \(y = 2\cdot{}3 - 6 = 0\) → точка \((3; 0)\).

Задание 2 (адаптация №283 из учебника)

Заполни таблицу для функции \(y = x(x - 3)\) на отрезке [−1; 4] и мысленно представь её график:

x−1011,5234
y???????

При каком x значение функции равно 0?

Вычисляем y = x(x - 3):
x = −1: \((-1)\cdot{}(-1 - 3) = (-1)\cdot{}(-4) = 4\)
x = 0: \(0\cdot{}(0 - 3) = 0\)
x = 1: \(1\cdot{}(1 - 3) = 1\cdot{}(-2) = -2\)
x = 1,5: \(1,5\cdot{}(1,5 - 3) = 1,5\cdot{}(-1,5) = -2,25\)
x = 2: \(2\cdot{}(2 - 3) = 2\cdot{}(-1) = -2\)
x = 3: \(3\cdot{}(3 - 3) = 3\cdot{}0 = 0\)
x = 4: \(4\cdot{}(4 - 3) = 4\cdot{}1 = 4\)
Таблица заполнена: 4; 0; −2; −2,25; −2; 0; 4
y = 0 при \(x = 0\) и при \(x = 3\) (это точки пересечения графика с осью X).
🔵 Уровень 2: Средний

Задание 3 (по мотивам №287 из учебника)

Функция задана графиком (парабола). По графику найди:

а) значение функции при x = 0; 2; 4;

б) при каких x значение функции равно 5;

в) при каких x функция принимает отрицательные значения.

Схема: парабола y = (x − 2)² − 1, проходящая через точки (0; 3), (1; 0), (2; −1), (3; 0), (4; 3)

Читаем график:
а) При x = 0: y = 3; при x = 2: y = −1; при x = 4: y = 3
б) y = 5: на показанном отрезке [0; 4] значение 5 не достигается (максимум y = 3 в концах). Если продолжить параболу: \((x − 2)^{2} − 1 = 5\) → \((x − 2)^{2} = 6\) → \(x − 2 = ±√6\) → \(x = 2 ± √6\), то есть \(x ≈ −0,45\) или \(x ≈ 4,45\)
в) Функция отрицательна, когда график ниже оси X — это при \(1 \lt x \lt 3\).
🔵 Уровень 2: Средний

Задание 4 (на основе №289 из учебника)

Измерив рост ребёнка в разные годы, построили график зависимости роста от возраста. Используя таблицу значений, ответь на вопросы:

Возраст (лет)246810
Рост (см)85100115125135

а) Каков был рост ребёнка в 3 года; в 6 лет; в 9 лет?

б) На сколько сантиметров вырос ребёнок за первые пять лет (с 2 до 7) и за следующие пять (с 7 до 12)?

Решение (интерполяция по таблице и графику):
а) В 3 года: между 2 годами (85 см) и 4 годами (100 см) — примерно (85 + 100) : 2 ≈ 92,5 см
В 6 лет: по таблице точно 115 см
В 9 лет: между 8 годами (125 см) и 10 годами (135 см) — примерно (125 + 135) : 2 = 130 см
б) За первые 5 лет (с 2 до 7 лет): рост в 7 лет — между 6 (115) и 8 (125), примерно 120 см. Прирост: 120 - 85 = 35 см
За следующие 5 лет (с 7 до 12 лет): рост в 12 лет — экстраполяция графика, примерно 145 см. Прирост: 145 - 120 = 25 см
Вывод: в первые годы дети растут быстрее! График роста в молодости круче, потом становится положе.

Задание 5 (№292 из учебника — эксперимент с водой)

Измеряли температуру воды в чайнике при нагревании. Получили таблицу:

t (мин)012345678910
T (°C)142841546676859398100100

Ответь на вопросы по графику нагревания:

а) Какая температура была через 4 мин; через 9 мин?

б) Через сколько минут температура стала равна 41°C; 60°C?

в) В какой промежуток времени нагревание шло интенсивнее всего?

г) Через сколько минут вода закипела?

д) Сколько минут продолжалось кипение (до конца наблюдения)?

Решение (по таблице и графику):
а) Через 4 мин: \(66^{\circ}C\); через 9 мин: \(100^{\circ}C\)
б) 41°C: через 2 мин (точно по таблице)
   60°C: между 3 мин (54°C) и 4 мин (66°C). Прирост за минуту 12°C, нужно набрать ещё 6°C от 54°C. Значит, через 3 + 6/12 = 3,5 мин
в) Считаем приросты по минутам: 14; 13; 13; 12; 10; 9; 8; 5; 2; 0 °C/мин. Интенсивнее всего нагревание шло между 0 и 1 минутами (прирост 14°C/мин); затем интенсивность постепенно снижалась
г) По таблице температура достигла 100°C через 9 мин после начала нагревания (в точке t = 9 уже 100°C)
д) Температура 100°C держалась как минимум с 9-й по 10-ю минуту — то есть 1 минуту = 60 секунд (в пределах нашего наблюдения)

Задание 6 (№293 — тормозной путь автомобиля)

На рисунке показаны графики зависимости тормозного пути автомобиля от скорости движения на сухом асфальте. По схеме графика ответь:

а) Чему равен тормозной путь при скорости 50 км/ч?

б) С какой скоростью должен ехать автомобиль, чтобы его тормозной путь не превышал 60 м?

в) Как изменяется тормозной путь при увеличении скорости?

Схема: тормозной путь растёт быстрее скорости (квадратичная зависимость S ≈ 0,006·v²)

Чтение схемы графика:
а) При скорости 50 км/ч находим точку на графике и смотрим её ординату: S ≈ 15 м
б) Находим на оси Y отметку 60 м, проводим горизонталь до графика, затем опускаем перпендикуляр на ось X: получаем скорость около 100 км/ч. Значит, чтобы тормозной путь не превышал 60 м, скорость должна быть не более 100 км/ч (по схеме)
в) Тормозной путь растёт быстрее скорости (по квадратичному закону): при удвоении скорости тормозной путь увеличивается в 4 раза! Именно поэтому превышение скорости так опасно 🚗
Вывод: даже небольшое увеличение скорости резко увеличивает тормозной путь — вот почему на дорогах такие строгие ограничения!

📝 Главное, что нужно запомнить

  • График функции — множество точек (x; y), где x — аргумент, y — значение функции
  • Чтобы построить график: составь таблицу значений → отметь точки → соедини их плавной линией
  • Чем больше точек — тем точнее график
  • График можно читать в обе стороны: x → y и y → x
  • Проверка принадлежности точки: подставь координаты в формулу и проверь равенство
  • Графики помогают понять закономерности без формул (температура, рост, скорость)
  • Форма графика рассказывает о характере зависимости (прямая — равномерный рост; парабола — ускоренный)
