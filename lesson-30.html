Глава 4 • §10, п. 30

Разложение многочлена на множители способом группировки

Когда общего множителя «на всех» нет, члены многочлена находят себе пару 🤝

Привет! 👋 Разомнёмся без калькулятора: сколько будет \(47\cdot{}8 + 47\cdot{}2 + 53\cdot{}8 + 53\cdot{}2\)? Не спеши перемножать «в лоб» — собери слагаемые в умные пары, и через десять секунд выйдет ровно \(1000\). Как это работает — тема урока: способ группировки из п. 30. Он выручает, когда у многочлена нет общего множителя для всех членов сразу, но общий множитель прячется внутри пар.

🧩 Когда общего множителя нет

В п. 28 мы выносили общий множитель за скобки. Но так везёт не всегда: у многочлена \(ab - 2b + 3a - 6\) нет множителя, который делили бы все четыре члена. Учебник сразу подсказывает выход: «Иногда удаётся разложить многочлен на множители, используя другой способ — группировку его членов».

Определение. Способ разложения многочлена на множители, при котором его члены объединяют в группы и из каждой группы выносят общий множитель, называют способом группировки. В учебнике: «Способ, который мы применили для разложения многочленов на множители, называют способом группировки».

🛒 Жизненная минутка. В канцелярии купили 8 тетрадей по 47 р., потом ещё 2 тетради по 47 р., а также 8 ручек по 53 р. и 2 ручки по 53 р. Стоимость покупки — \(47\cdot{}8 + 47\cdot{}2 + 53\cdot{}8 + 53\cdot{}2\). Считаем пары:

  1. \((47\cdot{}8 + 47\cdot{}2) + (53\cdot{}8 + 53\cdot{}2) = 47\cdot{}(8 + 2) + 53\cdot{}(8 + 2)\);
  2. в обеих скобках одно и то же \((8 + 2)\) — выносим его: \((8 + 2)\cdot{}(47 + 53)\);
  3. устно: \(10 \cdot{} 100 = 1000\) рублей.

Четыре умножения превратились в два сложения «десятков» — в этом и есть сила удачных пар. 🎯

👯 Алгоритм: собери пары

  1. Разбей четыре члена на две группы так, чтобы в каждой группе был свой общий множитель.
  2. Из каждой группы вынеси её общий множитель.
  3. Если в скобках появились одинаковые выражения — вынеси это выражение за скобки как общий множитель.

Пример 1 из учебника. Разложим на множители многочлен \(ab - 2b + 3a - 6\):

  1. Сгруппируем: \((ab - 2b) + (3a - 6)\) — в первой паре общий множитель \(b\), во второй \(3\).
  2. Выносим: \(b(a - 2) + 3(a - 2)\).
  3. Скобки совпали: \(b(a - 2) + 3(a - 2) = (a - 2)(b + 3)\).

Проверка умножением (п. 29): \((a - 2)(b + 3) = ab + 3a - 2b - 6\) — получили исходный многочлен. ✅

пара 1: \(ab\) и \(-2b\) пара 2: \(3a\) и \(-6\) общая скобка вынесена

Схема группировки для примера 1: члены соединяются в две пары, из каждой пары выносится свой множитель — и в скобках появляется одно и то же \((a - 2)\).

✂️ Если членов три — разрежь средний

Пример 3 из учебника. Разложим на множители трёхчлен \(a^2 - 7a + 12\). Группировать нечего? Тогда разрежем средний член:

  1. Представим \(-7a = -3a - 4a\): \(a^2 - 3a - 4a + 12\).
  2. Группируем: \((a^2 - 3a) + (-4a + 12) = a(a - 3) - 4(a - 3)\).
  3. Общая скобка: \((a - 3)(a - 4)\).

Обрати внимание на второй шаг: из группы \(-4a + 12\) мы вынесли \(-4\) — минус тоже бывает общим множителем. Благодаря ему знак внутри скобки перевернулся, и скобки совпали: \(-4a + 12 = -4(a - 3)\).

Проверка умножением: \((a - 3)(a - 4) = a^2 - 4a - 3a + 12 = a^2 - 7a + 12\) — верно. ✅

🔄 Две дороги — один результат

Группировать один и тот же многочлен можно по-разному. Возьмём снова \(ab - 2b + 3a - 6\) и соединим члены иначе — первый с третьим, второй с четвёртым:

  1. \((ab + 3a) - (2b + 6)\);
  2. выносим: \(a(b + 3) - 2(b + 3)\);
  3. общая скобка: \((b + 3)(a - 2)\).

Результат тот же, что в примере 1, просто множители поменялись местами. Правильных группировок может быть несколько — важен не путь, а совпадение скобок. Если скобки не совпали, не бросай решение: поменяй соседей по парам или вынеси из группы минус — и попробуй снова.

🎯 Методическая подсказка: Парный разведчик

Если общего множителя у всех членов нет — ищи ПАРЫ, как разведчик: разбей четыре члена на две группы, из каждой вынеси «своё» — и жди, когда в скобках появится одинаковое выражение. Совпало — выноси его вторым шагом. Не совпало — поменяй соседей по парам или вынеси минус.

Пример разведки: \(x^2\cdot{}y + x + x\cdot{}y^2 + y\). Пары по порядку: \((x^2\cdot{}y + x) + (x\cdot{}y^2 + y) = x(xy + 1) + y(xy + 1) = (xy + 1)(x + y)\). Две выноски — и совпадение ✅

✅ Контроль совпадения: годится и другая разбивка — \((x^2\cdot{}y + x\cdot{}y^2) + (x + y) = xy(x + y) + (x + y) = (x + y)(xy + 1)\). Тот же результат, множители лишь поменялись местами: обе группировки верны, если скобки совпали.

🚫 А пара «крест-накрест» заводит в тупик: \((x^2\cdot{}y + y) + (x + x\cdot{}y^2) = y(x^2 + 1) + x(1 + y^2)\) — в скобках разные выражения, дальше хода нет. Разведчик не сдаётся: меняет соседей — и скобки совпадают.

🧭 Мостик: в задании 2 соберёшь пары и заметишь в одной из них минус-множитель, а в задании 5 группировка заменит калькулятор.

✏️ Проверь себя

Задания взяты из учебника (п. 30) и идут от простого к сложному. Нажми «Проверить», чтобы увидеть полный ход решения!

🟢 Уровень 1: Лёгкий | Задание 1 (№725 а из учебника)

Разложите на множители многочлен: \(mx + my + 6x + 6y\)

Общего множителя у всех членов нет — собираем пары.

  1. Группируем: \((mx + my) + (6x + 6y)\).
  2. Из первой группы выносим \(m\), из второй \(6\): \(m(x + y) + 6(x + y)\).
  3. Скобки совпали — выносим \((x + y)\): \((x + y)(m + 6)\).

Проверка умножением: \((x + y)(m + 6) = mx + 6x + my + 6y\) — получили исходный многочлен.

Ответ: \((x + y)(m + 6)\)

🟢 Уровень 1: Лёгкий | Задание 2 (№725 г из учебника)

Разложите на множители многочлен: \(ax + ay - x - y\)

Пары видны сразу, но во второй спрятался минус.

  1. Группируем: \((ax + ay) + (-x - y)\).
  2. Из первой группы выносим \(a\), из второй выносим \(-1\) — минус-множитель: \(a(x + y) - (x + y)\).
  3. Скобки совпали: \((x + y)(a - 1)\).

Проверка умножением: \((x + y)(a - 1) = ax + ay - x - y\) — верно.

Ответ: \((x + y)(a - 1)\)

🔵 Уровень 2: Средний | Задание 3 (№726 б из учебника)

Разложите на множители многочлен: \(ax - 5 + 5x - a\)

Здесь «родные» пары стоят не рядом — сначала соберём их.

  1. Соединяем члены с \(x\) и «числовые»: \((ax + 5x) + (-5 - a)\).
  2. Выносим: \(x(a + 5) - (5 + a)\). Во второй скобке поменяем слагаемые местами: \(5 + a = a + 5\).
  3. Скобки совпали: \(x(a + 5) - (a + 5) = (a + 5)(x - 1)\).

Проверка умножением: \((a + 5)(x - 1) = ax - a + 5x - 5 = ax + 5x - a - 5\) — совпадает с исходным многочленом.

Ответ: \((a + 5)(x - 1)\)

🔵 Уровень 2: Средний | Задание 4 (№728 б из учебника)

Представьте в виде произведения многочлен: \(x^2 + 7x - ax - 7a\)

  1. Группируем: \((x^2 + 7x) + (-ax - 7a)\).
  2. Выносим \(x\) из первой группы и \(-a\) из второй: \(x(x + 7) - a(x + 7)\).
  3. Общая скобка \((x + 7)\): \((x + 7)(x - a)\).

Проверка умножением: \((x + 7)(x - a) = x^2 - ax + 7x - 7a = x^2 + 7x - ax - 7a\) — верно.

Ответ: \((x + 7)(x - a)\)

🟣 Уровень 3: Сложный | Задание 5 (№729 а из учебника)

Найдите значение выражения \(p^2\cdot{}q + p\cdot{}q^2 - p - q\) при \(p = 0,5\) и \(q = -0,5\)

Хитрость в том, чтобы сначала разложить на множители — тогда считать почти не придётся.

  1. Группируем: \((p^2\cdot{}q + p\cdot{}q^2) + (-p - q)\).
  2. Выносим \(pq\) из первой группы и \(-1\) из второй: \(pq(p + q) - (p + q)\).
  3. Общая скобка: \((p + q)(pq - 1)\).
  4. Подставляем \(p = 0,5\) и \(q = -0,5\): \(p + q = 0,5 + (-0,5) = 0\), поэтому \(0 \cdot{} (pq - 1) = 0\).

Проверка «в лоб»: \(0,25\cdot{}(-0,5) + 0,5\cdot{}0,25 - 0,5 - (-0,5) = -0,125 + 0,125 - 0,5 + 0,5 = 0\) — сошлось.

Ответ: \(0\)

🟣 Уровень 3: Сложный | Задание 6 (№731 а из учебника)

Докажите тождество: \(ax - y + x - ay = (x - y)(a + 1)\)

Преобразуем левую часть и покажем, что она совпадает с правой.

  1. Группируем члены левой части: \((ax + x) + (-y - ay)\).
  2. Выносим \(x\) из первой группы и \(-y\) из второй: \(x(a + 1) - y(a + 1)\).
  3. Общая скобка: \((a + 1)(x - y)\). Поменяем множители местами: \((x - y)(a + 1)\) — это правая часть тождества.
  4. Левая часть равна правой при любых значениях букв — тождество доказано.

Проверка умножением: \((x - y)(a + 1) = ax + x - ay - y\) — получена исходная левая часть.

Ответ: \(ax - y + x - ay = (x - y)(a + 1)\)

📝 Главное, что нужно запомнить

  • Если у всех членов многочлена нет общего множителя — попробуй способ группировки.
  • Алгоритм: пары → вынеси из каждой группы «своё» → вынеси совпавшую скобку.
  • Признак успеха — одинаковые скобки после вынесения; если они не совпали, поменяй соседей по парам или вынеси минус.
  • Минус бывает общим множителем: \(-x - y = -(x + y)\) — следи за знаками.
  • Трёхчлен тоже поддаётся: разрежь средний член на два слагаемых, как \(a^2 - 7a + 12\).
  • Правильных группировок может быть несколько — результат один и тот же.
  • Готово разложение — проверь умножением (п. 29): должно получиться исходное выражение.
  • Группировка экономит время и в арифметике: \(47\cdot{}8 + 47\cdot{}2 + 53\cdot{}8 + 53\cdot{}2 = 1000\) — устно.
