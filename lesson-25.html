Глава 4 • §8, п. 25

Многочлен и его стандартный вид

Команда одночленов выходит «в форме»: собираем дубли и ищем самого рослого 🧩

Привет! 👋 Открой любое трёхзначное число — например, 345. На самом деле это готовый многочлен: \(3 \cdot{} 10^2 + 4 \cdot{} 10 + 5\)! Сегодня мы официально познакомимся с многочленами — суммами одночленов, на которых построена вся вторая половина алгебры 7 класса. Научимся приводить их в порядок и измерять их «рост». 🚀

📦 Что такое многочлен?

Определение. Многочленом называется сумма одночленов.

Из учебника. Выражение \(4x^2y - 5xy + 8x - 1\) представляет собой сумму одночленов \(4x^2y\), \(-5xy\), \(8x\) и \(-1\) — это многочлен. Одночлены, из которых он составлен, называют членами многочлена.

Если многочлен состоит из двух членов — его называют двучленом, из трёх — трёхчленом. А одночлен считают многочленом, состоящим из одного члена.

4x^2y + -5xy + 8x + -1

Многочлен 4x²y − 5xy + 8x − 1: четыре члена — четыре карточки. Знак «минус» едет вместе с членом!

🧲 Подобные члены и приведение

Члены многочлена с одинаковой буквенной частью называют подобными членами. Например, в многочлене \(5a^2b + 2 + 4ab^2 - 3a^2b - 7\) подобны \(5a^2b\) и \(-3a^2b\), а также числа \(2\) и \(-7\).

Пример 1 из учебника. Приведём подобные члены в многочлене \(5a^2b + 2 + 4ab^2 - 3a^2b - 7\):

\(5a^2b + 2 + 4ab^2 - 3a^2b - 7 = (5a^2b - 3a^2b) + 4ab^2 + (2 - 7) = 2a^2b + 4ab^2 - 5\)

Сложение коэффициентов подобных членов называют приведением подобных членов многочлена.

Правило из учебника. Любой многочлен можно привести к стандартному виду: для этого нужно каждый его член представить в стандартном виде и привести подобные члены.

📏 Степень многочлена

У каждого члена многочлена стандартного вида есть своя степень. Возьмём многочлен \(4x^2y - 5xy + 8x - 1\) из начала урока:

\(4x^2y\) — степень 3 \(-5xy\) — степень 2 \(8x\) — степень 1 \(-1\) — степень 0

Правило из учебника. Степенью многочлена стандартного вида называют наибольшую из степеней входящих в него одночленов. Наш многочлен — пятой? Нет, третьей степени: самый «рослый» член \(4x^2y\).

Если многочлен ещё не приведён к стандартному виду, сначала приводят его к стандартному виду, а потом определяют степень тождественно равного ему многочлена.

Жизненный пример. Разряды числа — готовый многочлен: \(100a + 10b + c\). При \(a = 3\), \(b = 4\), \(c = 5\) он даёт ровно \(345\). Так работают номера, пароли и системы счисления!

🎯 Методическая подсказка: «Команда в форме»

Многочлен — это команда одночленов. Чтобы команда была «в форме», действуй по чек-листу:

  1. Каждый игрок сам в форме. Проверь каждый член: это одночлен стандартного вида? Пример: \(2b^3(-3)b c^2\) — не член, пока не превратился в \(-6b^4c^2\) ✅.
  2. Дубли — в один отряд. Одинаковая буквенная часть? Складывай коэффициенты: \(7mn + 4m + mn = 8mn + 4m\).
  3. Ловушка 🚫: \(7mn\) и \(4m\) — НЕ подобны (буквенные части разные!), их складывать нельзя. А \(3x^2y\) и \(-3xy^2\) — тоже НЕ подобны, хотя буквы те же: степени-то разные!

Мостик к заданиям: в задании 2 соберёшь дубли в многочленах с буквами, а в задании 3 вычислишь «рост» самого рослого члена — как в карточках выше.

🟢 Уровень 1: Лёгкий | Задание 1 (№583 а из учебника)

Назовите каждый член многочлена \(-6x^4 + y^5 - 5y + 11\).

Решение. Члены многочлена — это одночлены, из которых он составлен. Перечисляем их по порядку, не забывая про знак:

  1. Первый член: \(-6x^4\) (у него коэффициент \(-6\)).
  2. Второй член: \(y^5\) (коэффициент \(1\) — он «невидимый»).
  3. Третий член: \(-5y\).
  4. Четвёртый член: \(11\) (число — тоже одночлен, степень 0).

Ответ: \(-6x^4\), \(y^5\), \(-5y\), \(11\)

🟢 Уровень 1: Лёгкий | Задание 2 (№584 а, в из учебника)

Приведите подобные члены многочлена: а) \(10x^2 - 8xy - 3xy\); в) \(3x^4 - 5x + 7x^4 - 8x^3 + 5x\).

Решение. Подобные члены имеют одинаковую буквенную часть — складываем их коэффициенты.

  1. а) Подобны \(-8xy\) и \(-3xy\): \(-8 - 3 = -11\). Получаем \(10x^2 - 11xy\).
  2. в) Подобны \(3x^4\) и \(7x^4\): \(3 + 7 = 10\); подобны \(-5x\) и \(5x\): \(-5 + 5 = 0\) — они исчезают!
  3. Остаётся \(10x^4 - 8x^3\). Проверка подстановкой \(x = 1\): слева \(3 - 5 + 7 - 8 + 5 = 2\), справа \(10 - 8 = 2\) ✅.

Ответ: а) \(10x^2 - 11xy\); в) \(10x^4 - 8x^3\)

🔵 Уровень 2: Средний | Задание 3 (№586 а из учебника)

Представьте в стандартном виде многочлен \(-8p^4 + 12p^5 + 4p^4 - 8p^4 + 3p^5\).

Решение. Собираем «дубли»: подобны \(-8p^4\), \(4p^4\), \(-8p^4\) и \(12p^5\), \(3p^5\).

  1. Степени пять: \(12p^5 + 3p^5 = 15p^5\).
  2. Степени четыре: \(-8p^4 + 4p^4 - 8p^4 = (-8 + 4 - 8)p^4 = -12p^4\).
  3. Получаем \(15p^5 - 12p^4\). Проверка подстановкой \(p = 1\): слева \(-8 + 12 + 4 - 8 + 3 = 3\), справа \(15 - 12 = 3\) ✅.
  4. Порядок членов: по убыванию степеней — «рост самого высокого» впереди. Степень многочлена — 5.

Ответ: \(15p^5 - 12p^4\)

🔵 Уровень 2: Средний | Задание 4 (№590 из учебника)

Найдите значение многочлена \(2x^4 + 1\) при \(x = 0\); \(-2\); \(3\); \(-4\). Существует ли такое значение \(x\), при котором значение многочлена равно нулю; отрицательно?

Решение. Подставляем каждое значение — не забываем про скобки при отрицательных числах.

  1. \(x = 0\): \(2 \cdot{} 0^4 + 1 = 1\).
  2. \(x = -2\): \(2 \cdot{} (-2)^4 + 1 = 2 \cdot{} 16 + 1 = 33\) (минус исчез — степень чётная).
  3. \(x = 3\): \(2 \cdot{} 81 + 1 = 163\).
  4. \(x = -4\): \(2 \cdot{} 256 + 1 = 513\).
  5. Вывод: \(x^4 ≥ 0\) при любом \(x\), значит \(2x^4 + 1 ≥ 1\) — ни нуля, ни отрицательного значения не бывает 🚫.

Ответ: 1; 33; 163; 513; такого значения \(x\) нет

🟣 Уровень 3: Сложный | Задание 5 (№591 из учебника)

Докажите, что многочлен \(x^4 + y^4 + 1\) при любых значениях \(x\) и \(y\) принимает положительные значения.

Решение. Доказательство строится на одном факте: чётная степень любого числа неотрицательна.

  1. Для любого числа верно \(x^4 ≥ 0\) и \(y^4 ≥ 0\) (даже если \(x\) или \(y\) отрицательные — минусы «сгорают» в чётной степени).
  2. Тогда \(x^4 + y^4 ≥ 0\) — сумма неотрицательных чисел не может быть отрицательной.
  3. Прибавим 1: \(x^4 + y^4 + 1 ≥ 1 \gt 0\).
  4. Проверка «на попытку сломать»: минимум был бы при \(x = 0\) и \(y = 0\), но тогда значение равно \(0 + 0 + 1 = 1 \gt 0\) ✅ — и это наименьшее возможное значение.

Ответ: \(x^4 + y^4 + 1 ≥ 1\) — всегда положительно

🟣 Уровень 3: Сложный | Задание 6 (№592 из учебника)

Запишите в виде многочлена число, состоящее из: а) \(a\) десятков и \(b\) единиц; б) \(a\) сотен, \(b\) десятков и \(c\) единиц.

Решение. Разряды числа — это степени десятки. Живой пример: \(345 = 3 \cdot{} 100 + 4 \cdot{} 10 + 5\).

  1. а) \(a\) десятков — это \(10a\), плюс \(b\) единиц: получаем \(10a + b\).
  2. Проверка: \(a = 3\), \(b = 5\) → \(10 \cdot{} 3 + 5 = 35\) ✅.
  3. б) \(a\) сотен — \(100a\), \(b\) десятков — \(10b\), \(c\) единиц — \(c\): получаем \(100a + 10b + c\).
  4. Проверка: \(a = 3\), \(b = 4\), \(c = 5\) → \(300 + 40 + 5 = 345\) ✅. Степень такого многочлена — 2.

Ответ: а) \(10a + b\); б) \(100a + 10b + c\)

📝 Главное, что нужно запомнить

  • Многочлен — сумма одночленов; каждый одночлен в его составе называется членом многочлена.
  • Многочлен из двух членов — двучлен, из трёх — трёхчлен; одночлен считают многочленом из одного члена.
  • Члены с одинаковой буквенной частью — подобные члены многочлена; их складывают (приводят).
  • Привести многочлен к стандартному виду = каждый член сделать одночленом стандартного вида и привести подобные члены.
  • Степень многочлена стандартного вида — наибольшая из степеней его членов.
  • Значение многочлена удобно проверять подстановкой (например, \(x = 1\)) — до и после упрощения должно совпасть.
  • Чётные степени всегда неотрицательны: \(x^4 ≥ 0\) — на этом строятся доказательства положительности.
