Глава 2 • §5, п. 17

Кусочно-заданные функции

Когда одной формулы мало: собираем функцию из разных правил для разных промежутков 🧩

Привет! 👋 До сих пор мы рассматривали функции, которые на всей области определения задавались одной формулой (например, y = 2x или y = -3x + 1). Но в реальной жизни правило часто меняется «на ходу».

Турист из учебника шёл полтора часа со скоростью 6 км/ч, потом полчаса отдыхал, а затем шёл дальше со скоростью 5 км/ч. Одна формула такое не опишет — а три легко! Сегодня разберёмся, как устроены кусочно-заданные функции и как строить их графики без обидных ошибок на стыках. 🚀

📐 Что такое кусочно-заданная функция?

Определение. Функция называется кусочно-заданной, если её область определения разбита на промежутки и на каждом из них функция задаётся своей формулой.

Пример 1 из учебника (турист). Пока 0 ≤ t < 1,5, турист идёт со скоростью 6 км/ч: s = 6t. Во время привала (1,5 ≤ t ≤ 2) расстояние не меняется: он уже прошёл 6 · 1,5 = 9 км, значит s = 9. После привала (2 < t ≤ 3) он идёт со скоростью 5 км/ч: s = 9 + 5(t - 2) = 5t - 1. Короче:

{
6t, если 0 ≤ t < 1,5
9, если 1,5 ≤ t ≤ 2
5t - 1, если 2 < t ≤ 3

Схема: масштаб по осям не соблюдён

Читается запись так: «Смотри, в какой промежуток попало значение переменной, — ту формулу и применяй».

🔓 Модуль — это спрятанная кусочно-заданная функция

Пример 2 из учебника. Построим график функции y = x + 0,5|x|. Освободимся от знака модуля по определению:

  1. Если x < 0, то |x| = -x, значит y = x - 0,5x = 0,5x.
  2. Если x ≥ 0, то |x| = x, значит y = x + 0,5x = 1,5x.
{
0,5x, если x < 0
1,5x, если x ≥ 0

Схема: масштаб по осям соблюдён — луч слева (k = 0,5) положе луча справа (k = 1,5). Обрати внимание: при x < 0 значение y = 0,5x отрицательно, поэтому луч уходит вниз-влево.

График состоит из двух лучей, выходящих из начала координат: влево — пологий луч y = 0,5x, вправо — крутой луч y = 1,5x.

⚠️ Ловушка: одному x — только одно y

Задавая функцию несколькими формулами, следи, чтобы промежутки не перекрывались. Иначе одному значению переменной будут соответствовать два значения y — и это уже не функция!

🚫 Не функция: y = x при x ≤ 3 и y = 2x при x ≥ 3. Число x = 3 — общее значение переменной для обеих формул: получаем y = 3 и y = 6 сразу. Так не бывает!

✅ Функция: y = x + 1 при x ≤ 2 и y = 2x - 2 при x > 2. Граница x = 2 входит только в первый промежуток, значит у каждого x ровно одно значение y.

🎯 Методическая подсказка: алгоритм «Граница и Заклёпка»

Самые частые ошибки в кусочно-заданных функциях случаются на границе промежутков. Действуй по алгоритму:

  1. 📍 Найди границу. Это значение переменной, где формула-switch переключается (например, x = 2).
  2. 🧮 Посчитай y с обеих сторон. Подставь границу в левую и в правую формулу.
  3. 🔘 Поставь заклёпки по знакам неравенства:
    • нестрогий знак (≤, ≥) — точка принадлежит графику → закрашенный кружок;
    • строгий знак (<, >) — точка не принадлежит графику → выколотый кружок.
  4. Сшей или не сшивай. Если значения y с обеих сторон совпали — куски стыкуются в одной точке (график непрерывен). Если не совпали — это скачок: две точки на одной вертикали, соединять их отрезком нельзя!

Схема: масштаб по осям соблюдён — скачок на границе x = 2 для y = x + 1 (x ≤ 2) и y = 2x - 2 (x > 2)

💡 Контраст на одном примере: для y = x + 1 (при x ≤ 2) и y = 2x - 2 (при x > 2): слева y = 2 + 1 = 3 → точка (2; 3) закрашена ✅; справа предел 2 · 2 - 2 = 2 → точка (2; 2) выколота ✅. Значения не совпали — рисуем скачок и не соединяем точки. 🚫 Ошибка — закрасить обе точки или провести между ними отрезок.

🌉 Мостик: в задании 5 (№346) граница прячется в точке x = -1, а в задании 6 (№344) границу ты найдёшь сам из условия — примени алгоритм и расставь заклёпки правильно!

✏️ Проверь себя

Задания взяты из учебника (п. 17) и идут от простого к сложному. Нажми «Проверить», чтобы увидеть полный ход решения!

🟢 Уровень 1: Лёгкий | Задание 1 (№345 а из учебника)

Построй график функции:

{
y = -x, если x < -1
y = x, если x ≥ -1
  1. Кусок 1 (x < -1): луч прямой y = -x. Точки: (-3; 3), (-2; 2). На границе x = -1 получаем y = -(-1) = 1, но условие строгое (x < -1) — точка (-1; 1) выколота 🚫.
  2. Кусок 2 (x ≥ -1): луч прямой y = x из точки (-1; -1) (закрашена, потому что знак нестрогий) через (0; 0), (1; 1).

Стык: при x = -1 слева y = 1, справа y = -1 — значения не совпали, значит это скачок: точки (-1; 1) и (-1; -1) отрезком не соединяем 🚫.

Итог: график — «галочка» со скачком: левая ветвь спускается из верхнего левого угла к выколотой точке (-1; 1), а правая ветвь идёт из закрашенной точки (-1; -1) вверх-вправо через (0; 0) и (1; 1).

🟢 Уровень 1: Лёгкий | Задание 2 (№345 б из учебника)

Построй график функции:

{
y = 2x, если -1 ≤ x < 1
y = 3 - x, если 1 ≤ x ≤ 4
  1. Кусок 1 (-1 ≤ x < 1): отрезок прямой y = 2x: левый конец (-1; -2) закрашен; точки (0; 0); правый конец на границе: 2 · 1 = 2 → точка (1; 2) выколота.
  2. Кусок 2 (1 ≤ x ≤ 4): отрезок прямой y = 3 - x: левый конец 3 - 1 = 2 → точка (1; 2) закрашена; правый конец 3 - 4 = -1 → точка (4; -1) закрашена.

Стык: при x = 1 оба куска дают y = 2 — график непрерывен, «галочка» с вершиной в точке (1; 2) ✅.

Итог: отрезок вверх от (-1; -2) до (1; 2), затем отрезок вниз до (4; -1).

🔵 Уровень 2: Средний | Задание 3 (№348 б из учебника)

Построй график функции y = |x| + 0,5x. Сначала раскрой модуль и запиши функцию кусочно.

  1. Раскрываем модуль. Если x < 0, то |x| = -x: y = -x + 0,5x = -0,5x.
    Если x ≥ 0, то |x| = x: y = x + 0,5x = 1,5x.
  2. Кусочная запись:
{
-0,5x, если x < 0
1,5x, если x ≥ 0
  1. Строим два луча из начала координат. Левый луч (x < 0): через точку (-4; 2) (проверка: -0,5 · (-4) = 2 ✅). Правый луч (x ≥ 0): через точку (2; 3) (проверка: 1,5 · 2 = 3 ✅).

Итог: «уголок» с вершиной в точке (0; 0): влево — пологий луч вверх, вправо — крутой луч вверх. Не перепутай с примером 2 из теории: там модуль стоял при втором слагаемом, поэтому левый луч был другим!

🔵 Уровень 2: Средний | Задание 4 (№349 из учебника)

Функция задана следующим образом:

{
y = -x + 2, если x < 0
y = x + 2, если x ≥ 0

Задай эту функцию одной формулой, используя знак модуля.

  1. Сравниваем куски. Оба куска отличаются только знаком при x: слева -x, справа x, а «+2» общее.
  2. Вспоминаем модуль: |x| = x при x ≥ 0 и |x| = -x при x < 0 — в точности как наши куски!
  3. Собираем формулу: y = |x| + 2.

Проверка: при x = -5: |-5| + 2 = 5 + 2 = 7 и по куску -(-5) + 2 = 7 ✅; при x = 3: |3| + 2 = 5 и по куску 3 + 2 = 5 ✅.

Ответ: y = |x| + 2.

🟣 Уровень 3: Сложный | Задание 5 (№346 из учебника)

Построй график функции:

{
y = -x - 2, если x < -1
y = 2x + 1, если x ≥ -1

Определи, при каких значениях m прямая y = m и график данной функции: а) не имеют общих точек; б) имеют ровно одну общую точку; в) имеют ровно две общие точки.

  1. Граница x = -1: слева -(-1) - 2 = -1 (точка выколота), справа 2 · (-1) + 1 = -1 (точка закрашена). Значения совпали → вершина «галочки» в точке (-1; -1) ✅.
  2. Лучи: левый (x < -1) идёт вверх-влево, например через (-4; 2) (проверка: -(-4) - 2 = 2 ✅); правый (x ≥ -1) идёт вверх-вправо, например через (2; 5) (проверка: 2 · 2 + 1 = 5 ✅).
  3. Множество значений: левый луч даёт все y > -1, правый — все y ≥ -1. Значит наименьшее значение функции равно -1.
  4. Пересечения с горизонтальной прямой y = m:
    а) при m < -1 прямая проходит ниже графика — общих точек нет;
    б) при m = -1 прямая касается вершины — ровно одна общая точка (-1; -1);
    в) при m > -1 прямая пересекает оба луча — ровно две общие точки.

Ответ: а) m < -1; б) m = -1; в) m > -1.

🟣 Уровень 3: Сложный | Задание 6 (№344 из учебника, сюжетная задача)

Из бака ёмкостью 20 л, заполненного водой, через открытый кран равномерно вытекает вода со скоростью 2 л в минуту. Через кран может вытечь 0,9 всего объёма воды в баке, так как кран расположен выше дна бака. Объём воды V (в литрах) в баке зависит от времени x (в минутах), когда кран открыт. Задай зависимость V от x аналитически, если известно, что кран был открыт в течение 12 мин.

  1. Сколько воды может вытечь? 0,9 · 20 = 18 (л) — больше кран вылить не может.
  2. За какое время вытечет 18 л? 18 : 2 = 9 (мин). Значит первые 9 минут уровень падает, а с 9-й по 12-ю минуту из крана не капает — под ним остаётся 20 - 18 = 2 л.
  3. Первый кусок (0 ≤ x ≤ 9): за x минут вытекло 2x литров, осталось V = 20 - 2x. Проверка: x = 0 → 20 ✅; x = 9 → 20 - 18 = 2 ✅.
  4. Второй кусок (9 < x ≤ 12): объём не меняется: V = 2.
{
V = 20 - 2x, если 0 ≤ x ≤ 9
V = 2, если 9 < x ≤ 12

Граница и заклёпка: при x = 9 оба куска дают V = 2 — график непрерывен: отрезок вниз от (0; 20) до (9; 2), затем горизонтальный отрезок до (12; 2).

Ответ: V = 20 - 2x при 0 ≤ x ≤ 9; V = 2 при 9 < x ≤ 12.

📝 Главное, что нужно запомнить

  • Кусочно-заданная функция — функция, заданная разными формулами на разных промежутках области определения.
  • Чтобы найти значение функции, сначала определи, в какой промежуток попала переменная, и только потом применяй формулу.
  • Знак модуля часто «прячет» кусочно-заданную функцию: раскрывай его по определению (|x| = x при x ≥ 0, |x| = -x при x < 0).
  • Каждому значению переменной должно соответствовать ровно одно значение y — промежутки не должны перекрываться.
  • На границе промежутков ставь «заклёпки»: нестрогий знак — точка закрашена, строгий — выколота.
  • Если значения кусков на границе совпали — график непрерывен; не совпали — скачок, точки не соединяем.
  • График кусочно-заданной функции собирается из лучей, отрезков и точек — строй каждый кусок отдельно на своём промежутке.
