Глава 4 • §10, п. 29

Умножение многочлена на многочлен

Каждый член умножается на каждого: четыре клетки — и ни одну не потерять 🧩

Привет! 👋 В №720 учебника — прямоугольник с периметром 70 см: если длину уменьшить на 5 см, а ширину увеличить на 5 см, площадь вырастет аж на 50 кв. см. Как такое возможно и чему равны стороны? Чтобы сосчитать новые площади, придётся перемножать многочлены. Сегодня освоим правило «каждый с каждым» — и даже увидим, что этому правилу уже больше двух тысяч лет. 📐

🧭 Правило: каждый член — на каждый член

Правило. Чтобы умножить многочлен на многочлен, нужно каждый член одного многочлена умножить на каждый член другого многочлена и полученные произведения сложить.

Откуда правило берётся — вывод из учебника. Умножим \((a + b)(c + d)\). Обозначим двучлен \(a + b\) буквой \(x\) и применим правило п. 27:

  1. \((a + b)(c + d) = x(c + d) = xc + xd\).
  2. Подставим вместо \(x\) многочлен \(a + b\): \(xc + xd = (a + b)c + (a + b)d\).
  3. Снова умножим одночлены на многочлен: \((a + b)c + (a + b)d = ac + bc + ad + bd\).

Итак, \((a + b)(c + d) = ac + bc + ad + bd\) — сумма всех произведений «каждый с каждым». Произведение любых двух многочленов можно представить в виде многочлена.

📐 Чертёж Евклида и контроль «m на n»

Учебник рассказывает: древнегреческий математик Евклид в своём трактате «Начала» (III век до н.э.) доказывал это равенство геометрически — чертежом (в учебнике это рис. 83). Восстановим его на числах \(a = 3\), \(b = 2\), \(c = 4\), \(d = 1\): прямоугольник со сторонами \(a + b\) и \(c + d\) режется на четыре части.

Чертёж Евклида: четыре части площадью 12, 8, 3 и 2 дают в сумме 25 — ровно столько же, сколько \(5 \cdot{} 5\).

А вот контроль из учебника: при умножении многочлена из \(m\) членов на многочлен из \(n\) членов до приведения подобных должно получиться \(m \cdot{} n\) членов. Двучлен на двучлен — 4 произведения, трёхчлен на двучлен — 6. Пересчитал клетки — ничего не потерял. 🧮

🧮 Пример из учебника: трёхчлен на двучлен

Пример 1 из учебника: умножим \((4x^2 + 2xy - y^2)(2x - y)\). Три члена на два — выписываем все 6 произведений:

\(4x^2 \cdot{} 2x = 8x^3\) \(4x^2 \cdot{} (-y) = -4x^2y\)
\(2xy \cdot{} 2x = 4x^2y\) \(2xy \cdot{} (-y) = -2xy^2\)
\(-y^2 \cdot{} 2x = -2xy^2\) \(-y^2 \cdot{} (-y) = y^3\)

Складываем и приводим подобные: \(-4x^2y + 4x^2y = 0\) и \(-2xy^2 - 2xy^2 = -4xy^2\). Итог учебника: \((4x^2 + 2xy - y^2)(2x - y) = 8x^3 - 4xy^2 + y^3\). Было 6 слагаемых — стало 3.

⚖️ Упрощаем выражения

Пример 2 из учебника: упростим \((2a - 3)(5 - a) - 3a(4 - a)\).

  1. Перемножаем двучлены «каждый с каждым»: \((2a - 3)(5 - a) = 10a - 2a^2 - 15 + 3a\), после приведения подобных \(-2a^2 + 13a - 15\).
  2. Раскрываем вторую скобку (п. 27): \(-3a(4 - a) = -12a + 3a^2\).
  3. Складываем всё: \(-2a^2 + 13a - 15 - 12a + 3a^2 = a^2 + a - 15\).

Проверка числом при \(a = 2\): слева \(1 \cdot{} 3 - 6 \cdot{} 2 = -9\), справа \(4 + 2 - 15 = -9\) — сошлось. ✅ Следи за знаками: минус перед скобкой и минусы внутри клеток любят портить ответ.

🏟️ Жизненная задача: прямоугольник с сюрпризом

Вернёмся к №720 учебника. Пусть длина прямоугольника — \(x\) см. Раз периметр равен 70 см, то на длину и ширину вместе приходится 35 см, то есть ширина равна \(35 - x\) см. После изменений стороны станут \(x - 5\) и \((35 - x) + 5\) см, то есть \(40 - x\).

  1. Новая площадь: \((x - 5)(40 - x)\) — а это и есть умножение двучленов! Раскрываем: \(40x - x^2 - 200 + 5x\), то есть \(-x^2 + 45x - 200\).
  2. Старая площадь: \(x(35 - x) = 35x - x^2\).
  3. Разница площадей: \(-x^2 + 45x - 200 - 35x + x^2 = 10x - 200\). По условию она равна 50, откуда \(10x = 250\) и \(x = 25\).

Длина 25 см, ширина 10 см. Проверка: старый прямоугольник \(25 \cdot{} 10 = 250\) кв. см, новый \(20 \cdot{} 15 = 300\) кв. см — прибавка ровно \(50\) кв. см. 🏅 Вот так умножение многочленов выходит за страницы тетради.

🎯 Методическая подсказка: «Таблица каждый-с-каждым»

Перед тем как перемножать двучлены, рисуй на черновике мини-таблицу: строки — члены первой скобки, столбцы — второй. Каждая клетка — произведение. Для \((a + b)(c + d)\) клеток ровно 4: \(ac\), \(ad\), \(bc\), \(bd\). Контроль: 2 члена × 2 члена = 4 слагаемых до приведения подобных. Разберём \((x + 2)(x + 3)\):

· \(x\) \(+3\)
\(x\) \(x^2\) \(3x\)
\(+2\) \(2x\) \(6\)

Складываем клетки: \(x^2 + 3x + 2x + 6 = x^2 + 5x + 6\).

✅ Все 4 клетки собраны: \((x + 2)(x + 3) = x^2 + 5x + 6\).

🚫 Потеряли «крест» \(3x + 2x\) и написали \(x^2 + 6\) — клетка-ловушка съела два слагаемых. Считай клетки до приведения подобных!

🧩 Мостик: в задании 1 соберёшь все 4 пары «каждый с каждым», а в задании 4 после таблицы приведёшь подобные и вычтешь \(13y\).

✏️ Проверь себя

Задания взяты из учебника (п. 29) и идут от простого к сложному. Нажми «Проверить», чтобы увидеть полный ход решения!

🟢 Уровень 1: Лёгкий | Задание 1 (№693 а из учебника)

Выполните умножение: \((x + m)(y + n)\)

  1. Первый член первой скобки: \(x \cdot{} y = xy\) и \(x \cdot{} n = xn\).
  2. Второй член: \(m \cdot{} y = my\) и \(m \cdot{} n = mn\). Получилось ровно 4 произведения — 2 × 2, ничего не потеряли.
  3. Складываем: \((x + m)(y + n) = xy + xn + my + mn\). Подобных здесь нет, это готовый многочлен.
  4. Проверка числом: при \(x = 2\), \(m = 3\), \(y = 5\), \(n = 4\) слева \(5 \cdot{} 9 = 45\), справа \(10 + 8 + 15 + 12 = 45\) — сошлось.

Ответ: \(xy + xn + my + mn\)

🟢 Уровень 1: Лёгкий | Задание 2 (№694 а из учебника)

Упростите выражение: \((x + 6)(x + 5)\)

  1. Четыре произведения: \(x \cdot{} x = x^2\), \(x \cdot{} 5 = 5x\), \(6 \cdot{} x = 6x\), \(6 \cdot{} 5 = 30\).
  2. Контроль: до приведения подобных должно быть 4 слагаемых — все 4 на месте.
  3. Приводим подобные («крест»): \(5x + 6x = 11x\). Итог: \(x^2 + 11x + 30\).
  4. Проверка числом при \(x = 2\): слева \(8 \cdot{} 7 = 56\), справа \(4 + 22 + 30 = 56\) — сошлось.

Ответ: \(x^2 + 11x + 30\)

🔵 Уровень 2: Средний | Задание 3 (№698 а из учебника, степень в многочлен)

Замените степень произведением, а затем произведение преобразуйте в многочлен: \((x + 10)^2\)

  1. Степень — это произведение одинаковых множителей: \((x + 10)^2 = (x + 10)(x + 10)\).
  2. Четыре клетки: \(x \cdot{} x = x^2\), \(x \cdot{} 10 = 10x\), \(10 \cdot{} x = 10x\), \(10 \cdot{} 10 = 100\).
  3. Приводим подобные: \(10x + 10x = 20x\). Итог: \(x^2 + 20x + 100\).
  4. Проверка числом при \(x = 3\): слева \(13^2 = 169\), справа \(9 + 60 + 100 = 169\) — сошлось.

⚠️ Средние члены здесь одинаковые, но их всё равно два: степень умножает скобку саму на себя.

Ответ: \(x^2 + 20x + 100\)

🔵 Уровень 2: Средний | Задание 4 (№703 б из учебника)

Упростите выражение: \((7y - 4)(2y + 3) - 13y\)

  1. Четыре произведения: \(7y \cdot{} 2y = 14y^2\), \(7y \cdot{} 3 = 21y\), \(-4 \cdot{} 2y = -8y\), \(-4 \cdot{} 3 = -12\).
  2. Приводим подобные: \(14y^2 + 21y - 8y - 12 = 14y^2 + 13y - 12\).
  3. Вычитаем \(13y\): \(14y^2 + 13y - 12 - 13y = 14y^2 - 12\).
  4. Проверка числом при \(y = 2\): слева \((14 - 4)(4 + 3) - 26 = 70 - 26 = 44\), справа \(56 - 12 = 44\) — сошлось.

Ответ: \(14y^2 - 12\)

🟣 Уровень 3: Сложный | Задание 5 (№717 а из учебника, уравнение)

Решите уравнение: \((3x - 1)(5x + 4) - 15x^2 = 17\)

  1. Раскрываем произведение: \((3x - 1)(5x + 4) = 15x^2 + 12x - 5x - 4 = 15x^2 + 7x - 4\).
  2. Прибавляем \(-15x^2\): слева остаётся \(15x^2 + 7x - 4 - 15x^2 = 7x - 4\) — вторая степень исчезла.
  3. Уравнение стало линейным: \(7x - 4 = 17\), откуда \(7x = 21\) и \(x = 3\).
  4. Проверка подстановкой \(x = 3\): слева \(8 \cdot{} 19 - 135 = 152 - 135 = 17\) — верно.

Ответ: \(x = 3\)

🟣 Уровень 3: Сложный | Задание 6 (№718 из учебника, сюжетная задача)

Найдите три последовательных натуральных числа, если известно, что квадрат меньшего из них на 65 меньше произведения двух остальных.

  1. Пусть меньшее число — \(n\). Тогда два остальных: \(n + 1\) и \(n + 2\).
  2. Квадрат меньшего на 65 меньше их произведения, значит: \((n + 1)(n + 2) - n^2 = 65\).
  3. Раскрываем произведение: \((n + 1)(n + 2) = n^2 + 2n + n + 2 = n^2 + 3n + 2\).
  4. Подставляем в уравнение: \(n^2 + 3n + 2 - n^2 = 65\), откуда \(3n + 2 = 65\).
  5. Решаем: \(3n = 63\), значит \(n = 21\). Числа: 21, 22, 23.
  6. Проверка: \(22 \cdot{} 23 = 506\), квадрат меньшего \(21^2 = 441\), разница \(506 - 441 = 65\) — всё верно. ✅

Ответ: \(21; 22; 23\)

📝 Главное, что нужно запомнить

  • Чтобы умножить многочлен на многочлен, умножь каждый член одного многочлена на каждый член другого и сложи произведения: \((a + b)(c + d) = ac + bc + ad + bd\).
  • Контроль: до приведения подобных слагаемых должно быть \(m \cdot{} n\), где \(m\) и \(n\) — числа членов множителей.
  • Не теряй «крест» — два средних произведения чаще всего дают подобные: \((x + 6)(x + 5) = x^2 + 11x + 30\).
  • Степень двучлена — это его умножение на себя: \((x + 10)^2 = (x + 10)(x + 10)\).
  • Следи за знаками в каждой клетке: \(-y^2 \cdot{} (-y) = y^3\).
  • После раскрытия скобок приводи подобные — из 6 слагаемых может получиться 3.
  • Умножение многочленов решает уравнения со скобками и сюжетные задачи: площади, последовательные числа, работа бригад.
  • Проверяй себя подстановкой числа в обе формы выражения — значения должны совпасть.
