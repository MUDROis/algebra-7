Глава 1 • §1

Рациональные числа

Числа и выражения

Привет! 👋 Давай разберёмся с рациональными числами. Это важная тема, с которой ты будешь работать весь год. Представь, что все числа — это как матрёшка: каждое следующее множество включает в себя предыдущее!

📚 Что такое множества чисел?

В математике множество — это любая совокупность объектов, объединённых общим признаком. Например:

  • множество людей — граждан РФ
  • множество символов для записи математических выражений
  • множество окружностей с центром в данной точке

Мы сейчас будем рассматривать числовые множества.

💡 Как записать принадлежность

Чтобы записать, что число принадлежит множеству, используют знак ∈:

2 ∈ N — число 2 является натуральным

-2 ∉ N — число -2 не является натуральным

🎯 Три главных множества

N

Натуральные числа

1, 2, 3, 4, 5, ...

Те, что используем при счёте

от лат. naturalis — естественный

Z

Целые числа

..., -2, -1, 0, 1, 2, ...

Натуральные + противоположные + 0

от нем. Zahl — число

Q

Рациональные числа

Целые и дробные

Все целые + все дроби

от фр. quotient — отношение

Как они связаны?

Множество натуральных чисел является подмножеством множества целых чисел. А целые числа — подмножество рациональных.

N ⊂ Z ⊂ Q

Это значит: любое натуральное число — целое, а любое целое число — рациональное.

Круги Эйлера (визуализация)

Q Z N

N — натуральные (самое маленькое множество)
Z — целые (среднее)
Q — рациональные (самое большое)

🔍 Что такое рациональное число?

📐 Определение

Рациональное число — это число, которое можно записать в виде дроби m/n, где:

  • m — целое число
  • n — натуральное число (знаменатель не может быть нулём!)

Примеры представления:

1/2 = 2/4 = 40/80

-0,7 = -7/10 = -14/20

10,3 = 103/10 = 515/50

5 = 5/1 = 20/4

💡 Важное замечание

Среди всех дробей, которыми можно записать данное рациональное число, всегда можно указать дробь с наименьшим знаменателем. Она называется несократимой.

Для целых чисел такая дробь имеет знаменатель, равный 1.

Почему «рациональное»?

Термин произошёл от латинского слова ratio, что в переводе означает «отношение» или «частное». То есть рациональное число — это отношение двух чисел!

🎯 Методическая подсказка

🔥 Лайфхак: как перевести 0,(6) в обыкновенную дробь

Если ты затрудняешься, используй этот волшебный метод!

Шаг 1: Пусть x = 0,666...
Шаг 2: Умножим на 10:
10x = 6,666...
Шаг 3: Вычтем первое из второго:
10x - x = 6,666... - 0,666...
Шаг 4: Получаем:
9x = 6 → x = 6/9 = 2/3

✨ Вау-эффект гарантирован! ✨

🔢 Представление в виде десятичных дробей

Любое рациональное число можно представить в виде десятичной дроби. Для этого нужно разделить числитель на знаменатель.

Пример 1: Конечная десятичная дробь

Представим 1/8 в виде десятичной дроби:

1 ÷ 8 = 0,125

Деление закончилось — получилась конечная десятичная дробь.

Пример 2: Бесконечная периодическая дробь

Представим 8/37 в виде десятичной дроби. Делим 8 на 37:

8 ÷ 37 = 0,216216...

Остатки начинают повторяться: 8, 6, 23, 8, 6, 23... Значит, цифры в частном тоже будут повторяться: 2, 1, 6.

Что такое период?

Период — это повторяющаяся группа цифр в бесконечной десятичной дроби.

8/37 = 0,(216)

Читается: «ноль целых, двести шестнадцать в периоде».

Ещё примеры:

7/12 = 0,5833... = 0,58(3)

5 1/6 = 5,1(6)

-5/11 = -0,(45)

✨ Важное свойство рациональных чисел

📌 Запомни!

Каждое рациональное число может быть представлено в виде бесконечной десятичной периодической дроби.

Даже конечную десятичную дробь можно записать как бесконечную, приписав справа бесконечную последовательность нулей:

2,5 = 2,5000... = 2,5(0)
-3 = -3,000... = -3,(0)

Верно и обратное:

Каждая бесконечная десятичная периодическая дробь представляет некоторое рациональное число.

Например:

0,(3) = 1/3
2,(36) = 2 4/11
0,0(945) = 7/74

Исключение: период 9

Дроби с периодом 9 считают другой записью дробей с периодом 0:

0,(9) = 0,999... = 1,000... = 1
16,1(9) = 16,1999... = 16,2000... = 16,2

Поэтому дроби с периодом 9 заменяют дробями с периодом 0.

🚫 А что не рационально?

Бесконечные десятичные дроби, у которых нет периода, представляют числа, не являющиеся рациональными. Их называют иррациональными числами.

💡 Приставка «ир»

Приставка «ир» означает «отрицание». Иррациональные = не рациональные.

Иррациональные числа нельзя представить в виде отношения m/n, где m — целое, а n — натуральное.

Примеры иррациональных чисел:

3,010010001... (единицы разделяются последовательно одним, двумя, тремя и т.д. нулями)

-5,020022000222... (число нулей и число двоек каждый раз увеличивается на единицу)

π = 3,1415926... (отношение длины окружности к её диаметру)

Действительные числа

Множество рациональных чисел и множество иррациональных чисел составляют множество действительных чисел.

📌 Важно!

В курсе алгебры 7 класса все действия мы будем выполнять только с рациональными числами. Об иррациональных числах ты узнаешь подробнее в 8 классе.

Задание 1 (№1 из учебника)

Верно ли, что:

а) -4 ∈ N; -4 ∈ Z; -4 ∈ Q?

б) 5,6 ∈ N; 5,6 ∈ Z; 5,6 ∈ Q?

в) 28 ∈ N; 28 ∈ Z; 28 ∈ Q?

Ответ:
а) -4 ∉ N (нет, натуральные только положительные), -4 ∈ Z (да, целое), -4 ∈ Q (да, рациональное)
б) 5,6 ∉ N (нет), 5,6 ∉ Z (нет), 5,6 ∈ Q (да, рациональное)
в) 28 ∈ N (да), 28 ∈ Z (да), 28 ∈ Q (да)
Помни цепочку: N ⊂ Z ⊂ Q

📝 Главное, что нужно запомнить

  • N — натуральные (1, 2, 3...), Z — целые (натуральные + 0 + отрицательные), Q — рациональные (целые + дроби)
  • Цепочка включений: N ⊂ Z ⊂ Q
  • Любое рациональное число = m/n (m — целое, n — натуральное)
  • Дробь с наименьшим знаменателем — несократимая; у целых чисел знаменатель 1
  • Любое рациональное число можно представить в виде бесконечной десятичной периодической дроби
  • Период обозначается скобками: 0,(3) = 0,333...
  • 0,(6) = 2/3 — умножь на 10 и вычти исходное (лайфхак!)
  • Иррациональные числа — непериодические бесконечные дроби (изучим в 8 классе)
