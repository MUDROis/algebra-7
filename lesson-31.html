Глава 4 • §10, п. 31

Деление с остатком

Бонус-глава «Для тех, кто хочет знать больше»: что делать, когда нацело не делится 🧭

Привет! 👋 Ты добрался до пункта, который в учебнике помечен словами «Для тех, кто хочет знать больше», — это дополнительная глава для любознательных. Начнём с вопроса из жизни: какой день недели будет через 100 дней? Календарь не нужен — хватит деления с остатком: \(100 : 7 = 14\) (ост. \(2\)), значит, день недели сместится всего на 2. Остатки кажутся мелочью, а управляют большими циклами: днями недели, чётностью, классами чисел. 🗓️

🔢 Остаток у натуральных чисел

Пример из учебника: при делении числа \(143\) на \(7\) в частном получается \(20\) и в остатке \(3\): \(143 : 7 = 20\) (ост. \(3\)), причём остаток \(3\) меньше делителя \(7\). Тот же факт записывают равенством \(143 = 7 \cdot{} 20 + 3\).

Определение. Число \(r\) называется остатком от деления натурального числа \(a\) на натуральное число \(b\), если выполняются два условия: 1) разность \(a - r\) делится на \(b\); 2) \(0 ≤ r \lt b\).

Если одно натуральное число делится на другое без остатка, условились считать, что остаток равен \(0\).

Быстрая самопроверка на числах учебника: \(143 - 3 = 140 = 7 \cdot{} 20\) — разность \(a - r\) действительно делится на \(b\). ✅

➖ Целое делимое — тоже можно

Определение. Целое число \(r\) называют остатком от деления целого числа \(a\) на натуральное число \(b\), если разность \(a - r\) делится на \(b\) и \(0 ≤ r \lt b\).

Обозначив частное от деления \(a - r\) на \(b\) буквой \(q\), получим \(a - r = bq\), а отсюда — главную формулу всей темы:

\(a = bq + r\), где \(0 ≤ r \lt b\)

Пример из учебника: \(-13 = 5 \cdot{} (-3) + 2\), причём \(0 ≤ 2 \lt 5\). Частное от деления числа \(-13\) на \(5\) равно \(-3\), а остаток равен \(2\). А почему не \(q = -2\)? Тогда остаток вышел бы \(-13 - 5\cdot{}(-2) = -3\) — отрицательным, а так запрещено. 🚫

Запомни. Для любого целого числа \(a\) и натурального числа \(b\) существует единственная пара целых чисел \(q\) и \(r\) такая, что \(a = bq + r\), где \(0 ≤ r \lt b\).

Точки, кратные \(5\), делят прямую на отрезки длины \(5\). Число \(a = -13 = 5\cdot{}(-3) + 2\) попало в отрезок от \(-15\) до \(-10\): частное \(q = -3\), остаток \(r = 2\).

🗂️ Классы чисел по остаткам

Из учебника: «На делении с остатком основаны различные разбиения множества целых чисел на классы, т.е. на подмножества, не имеющие общих элементов». При делении на \(3\) могут получиться остатки \(0\), \(1\) и \(2\) — и все целые числа распределяются ровно по трём классам:

Остаток Класс Числа класса
\(0\) \(3k\) \(..., -6, -3, 0, 3, 6, ...\)
\(1\) \(3k + 1\) \(..., -5, -2, 1, 4, 7, ...\)
\(2\) \(3k + 2\) \(..., -4, -1, 2, 5, 8, ...\)

Здесь \(k\) — любое целое число. Знакомые примеры классов: чётные числа \(2k\) (остаток \(0\) при делении на \(2\)) и нечётные \(2k + 1\) (остаток \(1\)). Так же, по остаткам при делении на \(5\), все целые числа разбиваются на пять классов — от \(5k\) до \(5k + 4\).

🏠 Жизненные классы. Дома на одной стороне улицы — это класс \(2k\) (чётные), на противоположной — класс \(2k + 1\). А дни недели — классы по остаткам при делении на \(7\): прибавили к дате \(100\) дней — это \(14\) недель (остаток \(0\)) и ещё \(2\) дня, поэтому день недели сместится на \(2\).

📐 Бонус: многочлены тоже делят «уголком»

Раз уж мы в главе о многочленах — вот награда самым любознательным. Числа мы делим «уголком» по разрядам, а многочлены можно делить «уголком» по старшинству степеней. Формула \(a = bq + r\) работает и здесь, только остаток — это многочлен степени меньше степени делителя (аналог условия \(0 ≤ r \lt b\)).

x^2 + 5x + 8 x^2 + 2x ------------ 3x + 8 3x + 6 ------ 2 x + 2
x + 3

Деление «уголком»: \((x^2 + 5x + 8) : (x + 2) = x + 3\) (ост. \(2\)) — моноширинная запись помогает не потерять разряды.

Как это получено:

  1. Ведём деление по старшинству степеней: \(x^2 : x = x\) — первый член частного.
  2. Умножаем: \(x\cdot{}(x + 2) = x^2 + 2x\); вычитаем: \((x^2 + 5x + 8) - (x^2 + 2x) = 3x + 8\).
  3. Снова старшие степени: \(3x : x = 3\) — второй член частного.
  4. Умножаем: \(3\cdot{}(x + 2) = 3x + 6\); вычитаем: остаток \(2\).
  5. Степень остатка равна \(0\) и меньше степени делителя \(1\) — стоп.

Проверка по знакомой схеме «делитель · частное + остаток»: \((x + 2)(x + 3) + 2 = x^2 + 3x + 2x + 6 + 2 = x^2 + 5x + 8\) — верно. ✅ Привычка проверять деление умножением пригодится и числам, и многочленам.

🎯 Методическая подсказка: Уголок для многочленов

Дели «уголком» почти как числа: по старшинству степеней, от старшего члена к младшему. Закончи, когда остаток станет многочленом степени меньше делителя — это аналог условия \(0 ≤ r \lt b\). И финальный аккорд всегда один: делимое = делитель · (неполное частное) + остаток.

Пример: \((x^2 + 3x + 5) : (x + 1) = x + 2\) (ост. \(3\)). Проверка делением-умножением: \(x^2 + 3x + 5 = (x + 1)(x + 2) + 3 = x^2 + 3x + 2 + 3\) ✅

🚫 А если потерять остаток и записать просто \((x + 1)(x + 2) = x^2 + 3x + 2\), равенство с \(x^2 + 3x + 5\) не сойдётся: не хватает ровно \(3\). Остаток — не обрезок, а обязательная часть ответа!

🧭 Мостик: в задании 1 сделаешь ту же проверку делением-умножением для чисел: делимое = делитель · частное + остаток.

✏️ Проверь себя

🟢 Уровень 1: Лёгкий | Задание 1 (№738 а из учебника)

Найдите частное и остаток от деления \(138\) на \(7\)

Ищем пару чисел: частное \(q\) и остаток \(r\) такие, что \(138 = 7\cdot{}q + r\) и \(0 ≤ r \lt 7\).

  1. Ближайшее к \(138\) кратное \(7\): \(7\cdot{}19 = 133\) (а \(7\cdot{}20 = 140\) — уже больше).
  2. Остаток: \(138 - 133 = 5\).
  3. Условия выполнены: \(138 = 7\cdot{}19 + 5\) и \(0 ≤ 5 \lt 7\).

Проверка умножением: \(7\cdot{}19 + 5 = 133 + 5 = 138\) — верно.

Ответ: \(q = 19, r = 5\)

🟢 Уровень 1: Лёгкий | Задание 2 (№738 б из учебника)

Найдите частное и остаток от деления \(-16\) на \(3\)

Делимое отрицательное, но остаток обязан быть неотрицательным: \(0 ≤ r \lt 3\).

  1. Проба \(q = -5\): \(3\cdot{}(-5) = -15\), «остаток» \(-16 - (-15) = -1\) — отрицательный, не годится.
  2. Сдвигаем частное на единицу вниз: \(q = -6\), тогда \(3\cdot{}(-6) = -18\).
  3. Остаток: \(-16 - (-18) = 2\). Условие \(0 ≤ 2 \lt 3\) выполнено.

Проверка умножением: \(3\cdot{}(-6) + 2 = -18 + 2 = -16\) — верно.

Ответ: \(q = -6, r = 2\)

🔵 Уровень 2: Средний | Задание 3 (№734 а из учебника)

Разложите на множители трёхчлен: \(x^2 + 6x + 5\). Подсказка: приём «разрежь средний член» из прошлого урока всё ещё в деле.

  1. Представим \(6x = x + 5x\): \(x^2 + x + 5x + 5\).
  2. Группируем: \((x^2 + x) + (5x + 5) = x(x + 1) + 5(x + 1)\).
  3. Общая скобка: \((x + 1)(x + 5)\).

Проверка умножением: \((x + 1)(x + 5) = x^2 + 5x + x + 5 = x^2 + 6x + 5\) — верно.

Ответ: \((x + 1)(x + 5)\)

🔵 Уровень 2: Средний | Задание 4 (№740 из учебника)

Укажите все целые числа \(a\), которые при делении на \(7\) дают остаток \(3\), если \(-13 \lt a \lt 12\)

  1. Числа с остатком \(3\) при делении на \(7\) — это класс \(7k + 3\), где \(k\) — целое.
  2. Перебираем \(k\): \(7\cdot{}(-3) + 3 = -18\) — не входит; \(7\cdot{}(-2) + 3 = -11\) — подходит; \(7\cdot{}(-1) + 3 = -4\) — подходит; \(7\cdot{}0 + 3 = 3\) — подходит; \(7\cdot{}1 + 3 = 10\) — подходит; \(7\cdot{}2 + 3 = 17\) — не входит.
  3. Все четыре числа лежат строго между \(-13\) и \(12\).

Проверка: \(-11 = 7\cdot{}(-2) + 3\), \(-4 = 7\cdot{}(-1) + 3\), \(3 = 7\cdot{}0 + 3\), \(10 = 7\cdot{}1 + 3\) — у каждого остаток \(3\), и \(0 ≤ 3 \lt 7\).

Ответ: \(-11; -4; 3; 10\)

🟣 Уровень 3: Сложный | Задание 5 (№739 из учебника)

Найдите наибольшее целое отрицательное число, которое при делении на \(11\) даёт остаток \(1\)

  1. Все числа с остатком \(1\) при делении на \(11\) — это класс \(11k + 1\): \(..., -32, -21, -10, 1, 12, ...\).
  2. Число \(1\) (при \(k = 0\)) положительное — не годится, ищем отрицательное.
  3. При \(k = -1\): \(11\cdot{}(-1) + 1 = -10\) — отрицательное. При \(k = -2\) выходит \(-21\) — ещё меньше, и дальше числа только убывают.
  4. Значит, наибольшее из отрицательных чисел класса — \(-10\).

Проверка: \(-10 = 11\cdot{}(-1) + 1\), остаток \(1\), и \(0 ≤ 1 \lt 11\) — верно. Следующее число класса — \(1\), а оно уже положительное.

Ответ: \(-10\)

🟣 Уровень 3: Сложный | Задание 6 (№738 в из учебника)

Найдите частное и остаток от деления \(-4\) на \(5\). Ловушка задания: объясни, почему частное \(0\) не подходит.

  1. Условия: \(-4 = 5\cdot{}q + r\) и \(0 ≤ r \lt 5\).
  2. Ловушка! Вариант \(q = 0\) даёт «остаток» \(-4 - 5\cdot{}0 = -4\) — отрицательный, а так нельзя.
  3. Берём \(q = -1\): \(5\cdot{}(-1) = -5\), остаток \(-4 - (-5) = 1\).
  4. Условие выполнено: \(0 ≤ 1 \lt 5\). Других допустимых пар нет — остаток однозначно определяет частное.

Проверка умножением: \(5\cdot{}(-1) + 1 = -5 + 1 = -4\) — верно.

Ответ: \(q = -1, r = 1\)

📝 Главное, что нужно запомнить

  • Главная формула: \(a = bq + r\), где \(0 ≤ r \lt b\) — делимое = делитель · частное + остаток.
  • Остаток всегда меньше делителя, а для целых чисел — ещё и неотрицателен.
  • Если число делится нацело, остаток считают равным \(0\).
  • При отрицательном делимом частное может быть отрицательным: \(-16 = 3\cdot{}(-6) + 2\), \(-4 = 5\cdot{}(-1) + 1\).
  • Проверка всегда одна: делитель · частное + остаток = делимое.
  • Числа с одинаковым остатком при делении на \(b\) образуют класс: \(7k + 3\), а чётные \(2k\) и нечётные \(2k + 1\) — классы по делению на \(2\).
  • Многочлены тоже делятся с остатком: остаток — многочлен степени меньше делителя.
  • Любое деление проверяй умножением — и числа, и многочлены скажут спасибо.
