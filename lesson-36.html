Глава 5 • §12, п. 36

Разложение на множители суммы и разности кубов

Две последние формулы арсенала: собираем кубы в произведение 🧊

Привет! 👋 Представь два кубических аквариума: большой с ребром \(5\) дм и маленький с ребром \(2\) дм. Вместе они вмещают \(5^3 + 2^3 = 125 + 8 = 133\) литра. Сегодня ты научишься раскладывать такие суммы и разности кубов на множители — это две последние формулы сокращённого умножения, после них твой арсенал укомплектован полностью 🧰. А бонусом — молниеносные доказательства делимости огромных чисел, без единого столбика.

🧊 Формула суммы кубов

Начнём с суммы. Умножим двучлен \(a + b\) на трёхчлен \(a^2 - ab + b^2\) и посмотрим, что получится (так делает и учебник):

\((a + b)(a^2 - ab + b^2)\) = \(a^3 - a^2b + ab^2 + a^2b - ab^2 + b^3 = a^3 + b^3\)

Определение. Тождество \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\) называют формулой суммы кубов: сумма кубов двух выражений равна произведению суммы этих выражений и неполного квадрата их разности.

Почему квадрат «неполный»? Трёхчлен \(a^2 - ab + b^2\) напоминает \((a - b)^2 = a^2 - 2ab + b^2\), но вместо удвоенного произведения \(2ab\) в нём стоит просто \(ab\) — одного множителя не хватает, потому и «неполный».

Пример 1 из учебника — разложим на множители многочлен \(27x^3 + y^3\):

  1. Представим в виде суммы кубов: \(27x^3 + y^3 = (3x)^3 + y^3\).
  2. Первая скобка — сумма оснований: \(3x + y\).
  3. Хвост — неполный квадрат разности: \((3x)^2 - 3x \cdot{} y + y^2\).
  4. Итог: \(27x^3 + y^3 = (3x + y)(9x^2 - 3xy + y^2)\).

Проверка умножением: \((3x + y)(9x^2 - 3xy + y^2) = 27x^3 - 9x^2y + 3xy^2 + 9x^2y - 3xy^2 + y^3\) — средние члены исчезли, остаётся \(27x^3 + y^3\) ✅.

➖ Формула разности кубов

С разностью поступаем так же: умножим двучлен \(a - b\) на трёхчлен \(a^2 + ab + b^2\), который называют неполным квадратом суммы выражений \(a\) и \(b\):

\((a - b)(a^2 + ab + b^2)\) = \(a^3 + a^2b + ab^2 - a^2b - ab^2 - b^3 = a^3 - b^3\)

Определение. Тождество \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\) называют формулой разности кубов: разность кубов двух выражений равна произведению разности этих выражений и неполного квадрата их суммы.

Пример 2 из учебника — разложим на множители многочлен \(m^6 - n^3\):

  1. Представим в виде разности кубов: \(m^6 - n^3 = (m^2)^3 - n^3\) — ведь \((m^2)^3 = m^6\).
  2. Первая скобка: \(m^2 - n\).
  3. Хвост — неполный квадрат суммы: \((m^2)^2 + m^2 \cdot{} n + n^2\).
  4. Итог: \(m^6 - n^3 = (m^2 - n)(m^4 + m^2n + n^2)\).

Проверка: \((m^2 - n)(m^4 + m^2n + n^2) = m^6 + m^4n + m^2n^2 - m^4n - m^2n^2 - n^3\) — остаётся \(m^6 - n^3\) ✅. Обрати внимание: основания кубов бывают «высокими» — \(m^6 = (m^2)^3\), \(27x^3 = (3x)^3\), \(0,008 = 0,2^3\).

🪑 Кубик с хвостом: три правила знаков

Обе формулы устроены как игрушка «кубик с хвостом»: первая скобка — сумма или разность оснований (знак — как между кубами), а «хвост» — неполный квадрат. В хвосте живут три правила знаков:

  1. Старший член \(a^2\) — всегда с плюсом, знак сохраняется.
  2. Средний член \(ab\) — знак ПЕРЕВЁРНУТ: противоположен знаку первой скобки.
  3. Последний член \(b^2\) — всегда с плюсом.
Знак в «хвосте» \(a^3 + b^3\) \(a^3 - b^3\)
Первая скобка + (сумма) − (разность)
Старший член \(a^2\) + +
Средний член \(ab\) − (перевёрнут) +
Последний член \(b^2\) + +

Таблица знаков «кубика с хвостом»: старший член хвоста — всегда плюс, средний — перевёрнут относительно первой скобки, последний — всегда плюс

Соберём кубик по таблице: \(x^3 + 27 = x^3 + 3^3\). Первая скобка — \(x + 3\); хвост: старший \(x^2\), средний \(-3x\) (перевёрнут), последний \(+9\). Итог: \(x^3 + 27 = (x + 3)(x^2 - 3x + 9)\). Проверка: \(x^3 - 3x^2 + 9x + 3x^2 - 9x + 27 = x^3 + 27\) ✅.

🧮 Делимость без калькулятора

Зачем раскладывать кубы? Смотри, что видно из формул сразу: \(a^3 + b^3\) делится на \(a + b\), а \(a^3 - b^3\) — на \(a - b\). Докажем без столбиков, что \(4^3 + 2^3\) делится на 6:

  1. \(4^3 + 2^3 = (4 + 2)(4^2 - 4 \cdot{} 2 + 2^2)\).
  2. Первая скобка: \(4 + 2 = 6\) — это и есть наш делитель!
  3. Вторая скобка — целое число: \(16 - 8 + 4 = 12\). Значит, \(4^3 + 2^3 = 6 \cdot{} 12 = 72\) ✅.

И разность: \(5^3 - 2^3 = (5 - 2)(25 + 10 + 4) = 3 \cdot{} 39 = 117\) — делится на 3 ✅. Именно так строят задания на делимость в учебнике: не возводим огромные числа в куб, а достаём первую скобку. 🕵️

🎯 Методическая подсказка: «Кубик с хвостом»

Формулы кубов — «кубик с хвостом»: \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\) и \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\). Алгоритм: достань основание куба из каждого члена, собери первую скобку (знак — как между кубами) — хвост допишется по трём правилам: старший тот же, средний ПЕРЕВЁРНУТ, последний всегда «+».

Устный пример (не из заданий): \(64 + y^3 = 4^3 + y^3 = (4 + y)(16 - 4y + y^2)\) — хвост: \(16 = 4^2\), средний \(-4y\) (перевёрнут!), последний \(+y^2\). 🧊

✅ \(x^3 + 8 = (x + 2)(x^2 - 2x + 4)\) — средний знак перевёрнут, проверка умножением даёт ровно \(x^3 + 8\).

🚫 \((x + 2)(x^2 + 2x + 4)\) — забыли перевернуть средний знак: при раскрытии вылезает \(x^3 + 4x^2 + 8x + 8\), а это не \(x^3 + 8\).

🎯 Мостик: в задании 1 соберёшь два кубика с хвостом, в задании 2 — куб с «высоким» основанием, а в задании 5 первая скобка сама ответит на вопрос о делимости.

🟢 Уровень 1: Лёгкий | Задание 1 (№922 в, г из учебника)

Примените формулу суммы кубов или формулу разности кубов: \(x^3 - 64\); \(125 + a^3\)

В каждом выражении прячутся кубы — достаём основания и собираем «кубик с хвостом».

  1. \(x^3 - 64 = x^3 - 4^3\) — разность кубов с основаниями \(x\) и \(4\).
  2. Первая скобка: \(x - 4\). Хвост — неполный квадрат суммы: \(x^2 + 4x + 16\) (средний знак «перевёрнут» на плюс).
  3. Проверка умножением: \((x - 4)(x^2 + 4x + 16) = x^3 + 4x^2 + 16x - 4x^2 - 16x - 64\), остаётся \(x^3 - 64\) ✅.
  4. \(125 + a^3 = 5^3 + a^3\) — сумма кубов.
  5. Первая скобка: \(5 + a\). Хвост — неполный квадрат разности: \(25 - 5a + a^2\).
  6. Проверка: \((5 + a)(25 - 5a + a^2) = 125 - 25a + 5a^2 + 25a - 5a^2 + a^3\), остаётся \(125 + a^3\) ✅.

Ответ: \((x - 4)(x^2 + 4x + 16); (5 + a)(25 - 5a + a^2)\)

🟢 Уровень 1: Лёгкий | Задание 2 (№926 в из учебника)

Разложите на множители: \(x^6 - 8\)

Здесь спрятан «высокий» куб — основание будет не \(x\), а \(x^2\).

  1. Старший член: \(x^6 = (x^2)^3\) — куб основания \(x^2\).
  2. Младший член: \(8 = 2^3\). Значит, \(x^6 - 8 = (x^2)^3 - 2^3\) — разность кубов.
  3. Первая скобка: \(x^2 - 2\).
  4. Хвост: \((x^2)^2 + x^2 \cdot{} 2 + 2^2 = x^4 + 2x^2 + 4\).
  5. Итог: \(x^6 - 8 = (x^2 - 2)(x^4 + 2x^2 + 4)\).
  6. Проверка: \((x^2 - 2)(x^4 + 2x^2 + 4) = x^6 + 2x^4 + 4x^2 - 2x^4 - 4x^2 - 8\), остаётся \(x^6 - 8\) ✅.

Ответ: \((x^2 - 2)(x^4 + 2x^2 + 4)\)

🔵 Уровень 2: Средний | Задание 3 (№923 д из учебника)

Представьте выражение в виде суммы или разности кубов и разложите его на множители: \(125a^3 - 64b^3\)

Сначала превратим каждый член в точный куб — с коэффициентами.

  1. \(125a^3 = (5a)^3\), ведь \(5^3 = 125\).
  2. \(64b^3 = (4b)^3\), ведь \(4^3 = 64\).
  3. Получили разность кубов: \(125a^3 - 64b^3 = (5a)^3 - (4b)^3\).
  4. Первая скобка: \(5a - 4b\). Хвост: \((5a)^2 + 5a \cdot{} 4b + (4b)^2\).
  5. Считаем хвост: \(25a^2 + 20ab + 16b^2\).
  6. Проверка: \((5a - 4b)(25a^2 + 20ab + 16b^2) = 125a^3 + 100a^2b + 80ab^2 - 100a^2b - 80ab^2 - 64b^3\), остаётся \(125a^3 - 64b^3\) ✅.

Ответ: \((5a - 4b)(25a^2 + 20ab + 16b^2)\)

🔵 Уровень 2: Средний | Задание 4 (№924 а, в из учебника)

Разложите на множители: \(8 - m^3\); \(64x^3 + 1\)

Два кубика с хвостом: один на разность, другой на сумму.

  1. \(8 - m^3 = 2^3 - m^3\) — разность кубов.
  2. \(8 - m^3 = (2 - m)(4 + 2m + m^2)\) — в хвосте средний знак плюс.
  3. Проверка: \((2 - m)(4 + 2m + m^2) = 8 + 4m + 2m^2 - 4m - 2m^2 - m^3\), остаётся \(8 - m^3\) ✅.
  4. \(64x^3 + 1 = (4x)^3 + 1^3\) — сумма кубов.
  5. \(64x^3 + 1 = (4x + 1)(16x^2 - 4x + 1)\) — в хвосте средний знак минус.
  6. Проверка: \((4x + 1)(16x^2 - 4x + 1) = 64x^3 - 16x^2 + 4x + 16x^2 - 4x + 1\), остаётся \(64x^3 + 1\) ✅.

Ответ: \((2 - m)(4 + 2m + m^2); (4x + 1)(16x^2 - 4x + 1)\)

🟣 Уровень 3: Сложный | Задание 5 (№930 а, б из учебника, делимость)

Делится ли значение выражения: \(38^3 + 37^3\) на \(75\); \(99^3 - 74^3\) на \(25\)?

Возводить трёхзначные кубы не нужно — первая скобка формулы сама отвечает на вопрос.

  1. \(38^3 + 37^3 = (38 + 37)(38^2 - 38 \cdot{} 37 + 37^2)\).
  2. Первая скобка: \(38 + 37 = 75\) — ровно число из вопроса!
  3. Вторая скобка — целое число: \(1444 - 1406 + 1369 = 1407\). Значит, \(38^3 + 37^3 = 75 \cdot{} 1407 = 105525\) — делится на 75 ✅.
  4. \(99^3 - 74^3 = (99 - 74)(99^2 + 99 \cdot{} 74 + 74^2)\).
  5. Первая скобка: \(99 - 74 = 25\), вторая: \(9801 + 7326 + 5476 = 22603\). Значит, \(99^3 - 74^3 = 25 \cdot{} 22603 = 565075\) — делится на 25 ✅.
  6. Проверка в лоб: \(54872 + 50653 = 105525\) и \(970299 - 405224 = 565075\) ✅.

Ответ: да, делится на \(75\) и делится на \(25\)

🟣 Уровень 3: Сложный | Задание 6 (№933 а из учебника)

Решите уравнение: \((2x - 3)^2 - 2x(4 + 2x) = 11\)

Слева целое выражение — раскрой всё и приведи подобные, квадраты исчезнут.

  1. Квадрат двучлена: \((2x - 3)^2 = 4x^2 - 12x + 9\).
  2. Произведение: \(2x(4 + 2x) = 8x + 4x^2\).
  3. Вычитаем: \(4x^2 - 12x + 9 - 8x - 4x^2 = -20x + 9\) — квадраты взаимоуничтожились.
  4. Уравнение: \(-20x + 9 = 11\), отсюда \(-20x = 2\), то есть \(x = -0,1\).
  5. Проверка: \((-3,2)^2 + 0,2 \cdot{} 3,8 = 10,24 + 0,76 = 11\) ✅.

Ответ: \(x = -0,1\)

📝 Главное, что нужно запомнить

  • \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\) — формула суммы кубов.
  • \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\) — формула разности кубов.
  • Правила из учебника: сумма кубов равна произведению суммы выражений и неполного квадрата их разности; разность кубов — произведению разности выражений и неполного квадрата их суммы.
  • Знаки в «хвосте»: старший член — плюс, средний — перевёрнут, последний — всегда плюс.
  • Неполный квадрат отличается от полного: \(a^2 - ab + b^2\) вместо \(a^2 - 2ab + b^2\) — удвоения нет.
  • Основания бывают «высокими»: \(27x^3 = (3x)^3\), \(x^6 = (x^2)^3\), \(0,008 = 0,2^3\).
  • \(a^3 + b^3\) делится на \(a + b\), а \(a^3 - b^3\) — на \(a - b\): так доказывают делимость без вычислений.
  • Готовое разложение проверяй умножением — две минуты, а от ошибки страхует. 🧊
